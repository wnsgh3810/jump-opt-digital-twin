무릎 0.679 (설명력 0.991/0.997), 감쇠항은 0.2배 규약 동반. 저장소의 α 표 앵커

v9 는 거기서 안 나왔다.**

축소를 넣은 이유는 "그 시절 트윈이 실기보다 궤적을 훨씬 못 따라가 토크를 과대 예측"이었다.

- 실기: 힙 **8.124°**
- **현행 트윈(08-13): 힙 7.520° = 실기의 0.93배 → 축소 불필요(필요값 1.08)**

⇒ 배포 계획은 1.7배 못 따라가던 트윈 출력을 0.40배로 줄여 **1.37배 과소**로 남았다
(실측 피크가 계획의 1.49배인 것의 정체). **직접 측정**: 같은 목표각을 현행 트윈에 넣어

"실효게인 매칭 법칙 · 측정 hip α 0.55→0.38 램프 · label 60이 v9 계획보다 나은 점프"
