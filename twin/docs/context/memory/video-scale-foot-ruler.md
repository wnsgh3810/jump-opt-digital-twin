**발 롤러 실측 (사용자 확인 2026-08-08)**: 바깥 지름 **40.0 mm** = 금속 원판 **30.0 mm**
+ 고무 **5.0 mm** ×2. ⇒ **접지 반경 r = 20.0 mm** (MuJoCo `foot` geom 은 0.021 — 수정 필요).

영상 px→mm 자는 `code/goal23_fullspan/fs_vidscale.py`. 방사 기울기 원 맞춤이 잡는 경계는
**금속판/고무**다 (고무 바깥은 검은 그립패드와 명암차가 없어 안 잡힘) → **스케일 =
30.0 / 측정 px**. 26.07.23/150_2.2_250_3 = 32.50 px → **0.9231 mm/px**.

**★ 스케일은 영상마다 그 영상 자체에서 잰다** (사용자 지시) — 카메라 거리·줌이 세션마다 달라
발 px 지름이 다르다. 다른 trial 값 재사용 금지.

**독립 교차검증 3종이 일치해야 믿는다**: 발 금속판 0.923 · **골격 겹침**(MuJoCo thigh/calf
각 250mm 를 발에 앵커해 겹쳐 그리고 무릎이 실제 허브에 얹히는 스케일 선택) 0.92 ·
벽 눈금자(10cm=97.5px) 1.03. 폐기: 발판 플레이트 120mm(0.7453 — 금속판을 24.1mm 로 봄).

**추적 3원칙** (전부 실제 사고):
1. **적응 탐색창 + 등속 예측** — 고정 ±5px 는 푸시(프레임당 20~30px)에서 발을 놓친다.
2. **수직 구속**(win_y≈7px) — 가로만 넓히면 흰 플랫폼 **볼트 구멍**이 더 높은 점수로 이긴다.
3. **평활 금지** — 3프레임 이동중앙값이 푸시 급변을 −56.5→−38.5mm 로 깎았다.

**Why:** 자·추적창·평활 세 군데가 각각 틀려서, 사용자의 육안 관측을 **세 번** 반박했다.
전부 고치니 세 증언이 다 맞았다: 깊게 앉을 때 −7.9mm(육안 −10~15), 6.67~8.17s 이동
−7.7mm(육안 8.xx), 푸시 슬립 **−41.7mm**·Δx −56.5mm(육안 −60 = 플레이트 절반).
[[metric-provenance-rule]] 의 교과서적 사례 — **사용자 육안과 어긋나면 자·측정기부터 의심.**

**How to apply:** 영상 길이/슬립은 `fs_vidscale.scale_of()` + `track_roller()` 로만.
융합 슬립 = 영상 Δx(롤러 중심) − r·Δθ(엔코더). 최종: 푸시가 전체 슬립의 84%
(−42.0/−49.9 mm) — 접촉 모델은 이걸 재현해야 한다. `lint_footguns.py` 가 `mm_per_px`
직접 정의와 `_G_videoslip.json` 사용을 경고. 관련: [[robot-mass-slip-facts]],
[[foot-rolling-vs-slip]], [[marathon-g-transmission-260808]].
