**배경**: 점프높이 지표 정의 오류로 마라톤 D·E·F의 서사 일부가 무효화됨 → 사용자 지시로
**기준선을 OLD α(p24 + 커맨드층)로 원복**하고 재정합 시작. 아래는 그 시점의 지식 재고.

## A등급 — 시뮬 없이 데이터만으로 검증됨 (재정합에 그대로 가져갈 것)
1. **4ms(2샘플) qd 로깅 스큐**: desired 채널이 measured보다 2샘플 앞서 기록. 미보정 시 push에서
   kp·e가 25~30% 과대. → `FS_QDSHIFT=2`.
2. **실게인이 실측 토크를 재현**: 실측 상태로 τ2 재구성 시 실게인 13.52 vs 실측 13.94 (RMSE 0.85),
   OLD α(0.656/0.2)는 8.62 (38% 과소). **α는 커맨드층에서 물리적 근거 없음** — 단 α가 덮고 있던
   다른 것(힙 직렬 탄성)의 존재는 별개로 검증 필요.
3. **CVT 초기화 버그**: `init_meas`가 l_i≠30에서 평행사변형 관례로 폐쇄 모순 자세 생성 → 솔버 스냅.
   `qpos_from_crank` 정합 초기화로 수정 시 CVT CL q2 15.07→2.19° (−85%). **순수 버그픽스, 유지**.
4. **로봇 질량 3.26kg** (사용자 실측, 케이블 제거). 트윈 정본은 3.201 = 1.8% 부족.
5. **점프높이 정의** = 지면 기준 베이스 중심 최고높이 → 현행 배율 **1.003 (사실상 정확)**.
6. **발 = 반지름 ~20mm 롤러, 접지 = 그립테이프**(영상 확인), 정적 홀드 μ≥0.853 (26.8N/31.4N).

## B등급 — 관측은 사실이나 인과·필요성 미검증
- 힙 직렬 스프링(2단 96/323@9): α를 대체한다는 논리는 있으나 **독립 측정 없음**. 정지 토크-처짐
  직접 측정으로 검증 가능(미실시).
- 지지층 supp2가 push에서 +4~8J 양의 일: **측정은 사실**. 그러나 "그래서 점프가 과대"는 **반증됨**.
- 발 마찰 이력(Karnopp): 무슬립날 크리프 제거는 영상과 일치. 단 **슬립날 크기가 실측의 절반**
  (딥스쿼트 8~10mm vs sim 5mm).
- 토크 로그 = 2ms LPF + 20.5Nm 클립: 사용자 원리 동의, 정량 검증은 부분적.

## C등급 — 무효 또는 동기 상실
- "점프높이 8~25cm 과대(×1.2~1.5)" → **무효** (정의 오류).
- escrow(에너지 회계)·손실 재심·저장 증폭 축: 위 인과가 동기였으므로 **동기 무효**. 실험 결과 자체는
  기록으로 유효(게이트 탈락).
- fs14 τ2 21.65 목표: 재구성 바닥 22.40 아래 = 도달 불가 (이건 유효한 발견).
