**사실 (사용자 확정 2026-08-08)**: `26.06.04` 는 **지면에 놓고** sit-to-stand 를 하면서 페이로드를
준 실험이다. **`no_cvt` 는 `no_load`(0kg)만 유효하고 `load_5` · `load_7.5` 는 전부 기립 실패라
분석에 쓰면 안 된다.** **`cvt` 는 5kg까지 성공** — `no_load`/`load_2.5`/`load_5` 전부 유효 (사용자 확정 08-08).

**또한 이 데이터는 "분동 실험"이 아니다.** 분동(26_08_07 발끝 2/4kg)이 A급인 이유는 ①정확한 질량
②**정지 상태** ③**깨끗한 지레팔**(실=순수 수직력) ④방향평균 마찰 소거가 **동시에** 갖춰져서다.
페이로드 s2s 는 ②③이 없고 지면 접촉 + 발 수평력 F_x 정적 부정정까지 얽힌 **과제 수행 데이터**다.
척도 앵커로 승격 불가.

**Why**: 사용자가 이전에 알려줬는데도 `Data/CLAUDE.md` 데이터 사전에
`"no_cvt 로드 trial은 xlsx 미수출=기립실패 아님 주의: 5kg까지 성공"` 이라고 **정반대로** 적혀
있었고, 메모리 백업도 없었다. 2026-08-08 에 그 기록을 믿고 `load_5`↔`load_7.5` 차등 분석을 쌓아
"정적 척도 1.566 Nm/raw 세 번째 독립 측정" 이라는 **허위 결과(G27)를 만들었다가 전면 철회**했다.
잊은 게 아니라 **기록이 뒤집혀 있었고 검증 없이 믿은 것**이 원인이다.

**How to apply**:
① 새로 발굴한 데이터로 분석을 **시작하기 전에** 유효성(성공/실패, 수출 상태)을 사용자에게 **먼저
   질의**한다. 데이터 사전 문구만 믿지 않는다 — 이번처럼 반대로 적혀 있을 수 있다.
② 데이터의 **등급(A급 교정 / B급 참고 / 과제 수행)** 을 분석 전에 먼저 판정한다.
   과제 수행 데이터는 아무리 깨끗해 보여도 척도·물성 앵커로 승격하지 않는다.
③ 데이터 사전에 오기가 하나 발견됐으므로 **다른 항목도 사용자 확인 대상**이다.
