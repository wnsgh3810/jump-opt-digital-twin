2026-08-14. 사용자 지적: "무릎은 결국 조인트·모터고, 무거운 짐일수록 큰 토크를 요구하는
것 아닌가? 무게로 퉁쳐도 되나?" — **맞고, 모델은 이미 그렇게 돼 있다. 내 설명이 틀렸다.**

  무릎 손실 = (0.18 + fc1 · **|명령 토크|**) · tanh(무릎 각속도 / 0.3)

짐은 **몸통 질량으로만** 들어간다. 짐 → 더 큰 명령 토크 → 더 큰 손실. 사용자가 말한 경로 그대로다.
"짐이 무거울수록"이라고 쓴 것은 **결과를 기전인 것처럼** 말한 오류였다.

**물리**: 4절 링크의 핀과 감속기 기어 이를 누르는 힘이 전달 토크에 비례한다. 쿨롱 마찰은
누르는 힘에 비례하므로 손실도 토크에 비례 — 이것이 곧 **전달 효율**이다. 08-07 분동 왕복
실측이 정확히 이 형태였다: 무릎 0.135 + **0.1197**·|명령| (효율 88%) · 힙 0.278 + 0.0029 (≈100%).
무릎만 4절 링크와 벨트를 거치기 때문이다.

**Why (더 중요한 것):** 훑기가 고른 값 **0.45 는 실측 0.1197 의 3.8 배**(효율 88% → 55%).
링크 마찰이 그렇게 나쁠 리 없다 ⇒ **그 축이 마찰 아닌 무언가를 대신 떠맡고 있다.**
실측으로 확인한 후보: 점프 밀어내기에서 무릎 모터의 역기전력이 명령 토크 상위 10% 순간에
**공급 전압(24 V 가정)의 48%**, 속도 상위 구간에서 **103%** 인데 그때도 명령은 17.5 N·m 로
줄지 않는다. **힙은 19% 뿐** — 문제가 전부 무릎인 것과 일치한다.
(공급 전압 미기록 · 3상 유효전압 계수로 절대값 ±70% 불확실 — 사용자 확인 대기)

**How to apply:**
① 이 축을 "마찰"이라 부르지 말 것. **전달 효율 + 전압 한계의 혼합**이다.
② 그래서 6 회차는 **속도 의존 천장**(모터 전압 한계)을 같이 연다. 단독 교체는 안 된다 —
   열어 보니 일어서기 −29%·폐루프 토크 −2% 인데 **점프 높이 오차가 3.8 배**가 된다.
③ 준정적 실측은 하한이다 ([[quasistatic-is-lower-bound]]) — 초과 자체는 허용되지만
   3.8 배는 다른 성분의 존재를 가리키는 신호로 읽을 것.
