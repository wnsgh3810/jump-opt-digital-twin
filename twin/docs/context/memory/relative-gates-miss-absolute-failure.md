2026-08-12: 변속기 세션(26.04.29)의 무릎각 오차가 **26.8도**였다. 다른 세션은 1.1도다.
**24배**인데 게이트를 계속 통과했다 — 게이트가 "직전 스택 대비 +2% 이내"만 보기 때문이다.
처음부터 망가져 있으면 상대 비교로는 영원히 안 보인다.

원인은 물리가 아니라 채점 코드였다. 변속기 링크 길이 `l_i` 는 4절의 입력 링크라 **모델
치수 자체**인데(l_i 2mm 차 → 바디 2mm 차), 변속기 기하·폐쇄 초기화(`cvt_init`)·전달비
소산은 **전용 스크립트(`fs_cvt.py` 등)에서만** 모델에 실린다. 내가 새로 만든 채점판은
기본 트윈을 써서 변속기 trial 을 무변속 모델에 태웠다. 정본 경로로는 0.97도로 정상이다.

**Why:** `_GH3_eval` 같은 기존 스크립트에는 이미 `if cvt: continue` 가 있었다. **그 줄이
왜 있는지 확인하지 않고** 새 판을 짠 것이 사고의 직접 원인이다.

**How to apply:**
- 게이트에 **절대 수준 점검**을 하나 붙일 것 — 세션별 오차가 다른 세션 중앙의 몇 배인지.
  배수가 튀는 세션은 "통과"여도 경보를 띄운다.
- **새 채점판을 만들 때 기존 스크립트가 어떤 세션을 왜 빼는지부터 읽을 것.** 필터는 대개
  이유가 있다.
- 변속기(l_i≠30) 세션은 기본 트윈으로 채점 **불가**. `python fs_cvt.py cl` 로 따로 본다.
