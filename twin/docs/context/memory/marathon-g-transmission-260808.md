**2026-08-08 마라톤 G 핵심 성과** (로그: `<repo>/code/goal23_fullspan/MARATHON_G_REFIT.md` G10~G40)

**기록 구성** — `FS_TMAP=canon_cap FS_TDCAP=3.5,2.4` + `FS_NOSUPP/NOSPR/NOBIAS/NODEEP=1`
+ `FS_PRESLIDE=0.86,0.85,0.02,2.0` → **J_G = 0.7519** (p24 ≡ 1.000), 게이트 PASS.
held-out 0324 가 **최대 개선** (q1 −34.5% · q2 −38.0% · dq2 −37.8%) = 일반화 확인.
점프높이 예측 오차 5.78% → **4.37%**.

**★ 가장 중요한 발견: `canon_cap` 은 접착제가 아니라 물리다.**
`τ = a_hat + clip(정본 − a_hat, ±cap)` 의 실효 출력을
`정본(raw) − (fc0 + fc1·|raw|)·tanh(v/v0)` 로 재적합하면 **R² 0.976**, 그리고
**fc1 ≈ 0.31 이 무릎·힙 양 채널에서 동일**. 0.31/1.24 = **25%**
⇒ **전달 토크의 25% 가 마찰로 소산 = 효율 75% 전동계.**
분동은 **정지** 상태라 손실이 없고, 점프는 **움직이므로** 손실이 있다. 두 환율표가 달랐던 이유.
a_hat 은 같은 손실 항을 **5.2%** 로 잡고 대신 이득을 절반(0.682 vs 1.24)으로 깎아
**두 오류가 서로를 가려주고** 있었다.

**독립 3중 확인** — ①분동(정지, A급) = 이득 1.24 Nm/raw ②에너지 장부(점프) = 실효 일이
a_hat 의 1.19~1.33배 ③J_G 최적 형태 = 정본 − 0.31|raw|. "정본 − 25% 손실"의 에너지 배율은
**1.244×** 로 ②의 한복판. 순수 정본(손실 없음)은 1.808× 로 과대.

**★★ 두 번째 핵심 발견: `α` 표(무릎 TK 0.85/0.789/0.656/0.40)도 물리가 아니었다** (G49-B).
정본 토크맵 아래서 α 배율을 0.45→1.0 스캔하니 **완벽히 단조**로, α 가 클수록 폐루프 CL 의
**q1·q2·τ1·τ2 네 축이 전부 동시에** 좋아졌다. 최적은 **α = 1.0 = 보정 완전 제거**.
- α<1 은 sim 명령 s2 를 실측 raw2 보다 **구조적으로 작게** 만든다 → τ-fidelity 를 정의상 해친다.
- 구 트윈에서 통했던 건 **a_hat 이 명령당 토크를 1.82배 적게 냈기** 때문 — 두 오류의 상쇄.
- 사용자의 오랜 질문 **"왜 0.656/0.2 로 잘 맞았나"의 답**이다.
- "실효 강성 보존"이라는 물리 예측(α×0.55)은 **정반대로 반증**됐다 (CL q2 +144%).
- 단 **kd×0.20 은 벗겨지지 않는다** (힙은 1.0 선호, 무릎은 0.2 선호 = 진짜 트레이드오프)
  ⇒ kd 0.2 는 α 와 **다른 실체**(속도 신호 필터 후보). 유지.
