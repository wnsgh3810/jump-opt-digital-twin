모델은 명령 토크를 축 토크로 바꿀 때 **어느 크기에서나 0.65~0.68 배**를 쓴다 (직접 확인,
명령 0.2~15 N·m 전 구간). 분동 실험(26.08.07)이 준 값은 **저토크 1.26 → 고토크 0.86** 으로
크기에 따라 변한다. 점프는 명령 10~15 N·m 라 어긋남이 1.3 배지만, **매달린 실험은
0.2~1.2 N·m 라 1.85 배** 어긋난다. 적합 8 세션이 전부 점프라 저토크가 한 번도 구속된 적이 없었다.

독립 증거 (매달린 채 멈춘 순간 6,900 개, 자세 8 칸): 힙 명령 ÷ "모델이 필요하다는 유지토크"
= 0.45~0.67 (중앙 0.55) 인데 로봇은 버틴다. 모자란 몫을 정지 마찰이 받아야 하는데
· 환산 1.26 가정 → 축 0.71, 부족 0.30 ↔ 실측 힙 마찰 0.278 (8% 차) ✔
· 모델 0.68 그대로 → 축 0.38, 부족 0.63 ↔ 실측 마찰의 2.3 배 ✘

**정적 시험만으로는 마찰과 환산비를 분리 못 한다** — 멈춘 순간의 자세가 거의 안 변해
필요토크가 0.075 N·m 폭으로만 움직인다 (직선 맞춤 설명력 0.116). 둘 다 탐색 축으로 넣고
움직이는 데이터가 가르게 할 것. [[quasistatic-is-lower-bound]] 와 같은 함정.

무릎은 매달리면 **정지 마찰이 거의 전부 받는다** (중력 요구 0.13~0.28 N·m, 명령 중앙
+0.04 N·m). 무릎 정지 마찰 하한 0.227 N·m — 사용자 관찰 "모터 꺼도 무릎은 안 움직인다"와 일치.
