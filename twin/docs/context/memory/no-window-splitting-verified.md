2026-08-14. 사용자 상시 규칙 **"창 분할 재생 금지"** 를 어겼다. 내가 넣은 일어서기 채점이
1.9 초 동작을 2~3 조각으로 나눠 각각 실측 상태로 재시작해 쟀다. 근거로 든 것은
"개루프는 되돌려 주는 힘이 없어 2 초면 발산하니 나눌 수밖에 없다" 였는데 **검증 안 한 가정**이었다.

**낮 판정(불충분)**: 세 모델로 재니 벌어짐이 통짜 45% · 나눈 것 51% 로 비슷 → "나눌 필요 없다".

**저녁 확정(뒤집힘)**: 하중 비례 무릎 손실 축을 0→0.80 까지 실제로 훑어 보니 결론이 강해졌다.

| | 지금 모델 | 최적점(fc1=0.50) | 벌어짐 |
|---|---|---|---|
| **통짜 성적** | 6.281 | **0.783** | **8.0 배** |
| 나눈 성적 | 3.163 | 1.401 | 2.3 배 |

**나눈 판에는 바닥(≈1.40)이 있어 그 아래를 못 본다.** 짧은 창은 신호가 조금밖에 안 움직여
분모가 작고, 시작 과도와 잡음이 지배하기 때문이다. ⇒ **조각내면 좋은 모델을 알아보지 못한다.**
낮의 "사실상 같다"는 비교한 세 모델이 다 비슷한 자리에 있어서 나온 착시였다.

**Why:** ① "이 지표는 못 쓴다"는 판단도 **측정으로 확인해야 하는 주장**이다 — 특히 그것이
사용자 규칙을 어기는 근거일 때는. ② 그리고 **판의 구분력은 좁은 범위의 모델 몇 개로 재면
안 된다.** 축을 넓게 훑어 놓고 재야 바닥(포화)이 보인다. 낮의 오판이 정확히 이 함정이었다.
**How to apply:** ① 느린 동작 판은 **창을 나누지 않고 한 번에** 돌린다 (원칙만이 아니라
성능에서도 옳다). ② 발산 대비로 채널당 상한(10)과 **"오차가 10도를 넘을 때까지 버틴 시간"**
(초 단위·천장 없음)을 병기한다. ③ 새 판의 구분력을 평가할 땐 **후보를 넓게 벌려 놓고** 재라.
