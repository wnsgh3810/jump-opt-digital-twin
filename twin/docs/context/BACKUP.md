## 왜 이렇게 나눠 뒀나

`Data` (실험 원본 4 GB) · `jump_opt` (35 GB) · `AVT LEG` (19 GB) 는 **git 밖**에 둔다.
git 안에 넣으면 ① 용량이 두 배가 되고 ② 워크트리 만들기가 8초에서 수십 분이 된다.
**끝난 결과물에 필요한 것은 이력이 아니라 사본**이므로, 위 D 드라이브 백업이 그 역할을 한다.

## 백업을 새로 뜨려면

```
robocopy "C:\Users\junho\CVT" "D:\CVT_backup_260816" /E /MT:16 /R:1 /W:1 /NFL /NDL /NP
```
(바뀐 파일만 복사한다. 검증은 `/L` 을 붙여 다시 돌려 "복사할 것 0" 을 확인.)

⚠️ 명령을 셸 한 줄로 넘기면 따옴표가 깨져 **0개 파일을 복사하고도 성공 신호를 낸다.**
실제로 그렇게 한 번 실패했다. `.bat` 파일로 만들어 돌리고, **끝나면 반드시 개수·용량을 대조**할 것.
