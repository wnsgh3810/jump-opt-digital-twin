## 2. 2 회차는 무엇을 쓰나 — 이름이 겹치지 않는다

| 1 회차 (건드리지 않음) | 2 회차 (새로 씀) |
|---|---|
| `_GHB_sweep.json` | `_GHB_sweep2.json` |
| `_GHB_sweep.log` | `_GHB_sweep2.log` |
| `_GHB_sweep_trials.jsonl` | `_GHB_sweep2_trials.jsonl` |
| `_GHB_sweep.bat` | `_GHB_sweep2.bat` ← **이걸 더블클릭** |

시동 파일이 `FS_SWEEP_TAG=2` 를 켜서 이름 뒤에 2 를 붙인다. 1 회차 파일에는 아무 일도
일어나지 않는다.

## 3. 되돌리는 절차

### (가) 2 회차 결과가 마음에 안 든다 — 그냥 안 쓰면 된다
현행 스택은 **승격 절차를 밟기 전까지 바뀌지 않는다.** 2 회차는 파일만 남길 뿐
현행 값을 자동으로 갈아치우지 않는다. 아무것도 안 해도 지금 상태가 유지된다.

### (나) 코드를 어제 상태로 되돌리고 싶다
2 회차용 코드 변경은 전부 커밋돼 있다. 되돌릴 지점:

| 되돌릴 곳 | 명령 |
|---|---|
| 변속기 복귀 **직전** (어제 밤 상태) | `git checkout c1bee42 -- code/goal23_fullspan code/bench` |
| 변속기 복귀까지만 (스윕 설정 변경 전) | `git checkout 4165d00 -- code/goal23_fullspan` |

· `c1bee42` = 08-12 낮 인수인계 파일까지. 변속기는 판에서 빠진 상태.
· `4165d00` = 변속기 복귀 + 링크 손실 결함 수정까지. **여기가 검증이 끝난 안전 지점이다.**

### (다) 스윕 없이 지금 상태를 확인하고 싶다
```
cd code/goal23_fullspan
python _GHB_sweep.py board                    # 변속기 포함 판 (적합 8 세션)
FS_SWEEP_CVT=0 python _GHB_sweep.py board     # 변속기 제외 판 (적합 7 세션, 0.96449 나와야 정상)
```

## 4. 2 회차를 판정하는 기준 (미리 못 박아 둔다)

이겨야 할 상대는 **1.0000 이 아니라 현행 스택 점수**다. 점수는 그 전 스택(H2)을
1.0000 으로 놓은 배율이고 낮을수록 정확하다.

| 판 | 현행 스택(H3) 점수 | 2 회차가 이 밑으로 내려와야 승격 후보 |
|---|---|---|
| 적합 8 세션 (변속기 포함) — **이번 판** | **0.96143** | ✔ 이 값 |
| 적합 7 세션 (변속기 제외) — 참고 | 0.96449 | — |

추가로 전부 만족해야 한다:
- 따로 떼어둔 데이터 검사 3 종 벌점 0 (별도 보관본 0324 · 위치제어 0421)
- 기존 모델 재현 (`bench eval` 이 REPRODUCED)
- 발 미끄러짐 비악화 (이 점수에 안 들어가 있으므로 따로 확인)
- 경계에 붙어 멈춘 값이 몇 개인가 (붙으면 범위를 넓히지 말고 물리를 재검한다)
