# P25 — 배포 리허설 마라톤: 최적화 총력전 → PD 배포 → τ-fidelity (노션 초안)

> 게시 구조 (사용자 표준 워크플로우: 구조 → 부분별 → 그래프 다양 → 비유+논리+수식)
> 상위 페이지: GOAL22 허브 아래 "P25 배포 리허설" 1페이지 + 하위 섹션 토글

## 0. 한 줄 요약 (콜아웃)

승격된 p24a 디지털 트윈 위에서 6가지 방법으로 점프를 최적화하고 전부 PD로 "배포"해 본 결과 —
**트윈에서 학습한 RL(PPO) 궤적 + FF+PD 배포(실기에 이미 있는 채널) = 점프 1.36m (실측 최고 +0.37m)를
계획 토크 오차 4.0%로 실현.** "측정 τ ≈ 계획 τ*"라는 연구 최종 목적의 전면 예행 성공.

## 1. 왜 이 마라톤인가 (배경)

- 헌법의 최종 목적: 최적화 궤적 (q_des, dq_des)로 실로봇 PD 제어 시 측정 토크 ≈ 계획 토크 τ*.
- 지금까지: 트윈 정밀화 (P19~P24, 최종 p24a). 이번: 그 트윈 **위에서** 목적 전체를 예행.
- 비유: 비행 시뮬레이터를 정밀하게 만든 다음 (P24까지), 이제 그 시뮬레이터 안에서
  실제 조종 절차(이착륙 매뉴얼 = 배포 절차)까지 리허설.
- 트윈 안 리허설이므로 F_τ의 성분 = **PD 추종 한계 + 궤적의 공격성** (모델 오차 아님).
  실기 배포 시 여기에 모델 오차가 가산된다.

## 2. 지표 (선고정)

```
h_plan  = 최적화기 자신의 롤아웃 apex [m]
h_PD(g) = (q_des,dq_des)를 게인 g로 트윈 폐루프 PD 배포했을 때 apex [m]
F_τ(g)  = RMSE(τ_PD − τ*) / RMS(τ*)   (스탠스 구간; 낮을수록 계획 토크에 충실)
게인 2종: mid = 120/2/120/2, high = 150/2.2/500/4 (실험 폴더 게인)
```
- 공급 천장: raw ±35.5 (실측 클립) → a_hat 경유 축토크 최대 ≈ 20.2Nm.
- 실측 최고 점프 0.98m (0602) / G20 계획 1.063m이 기준선.

## 3. 채점 눈금의 발견 — 철칙 10의 최초 완전 정량화 (D 하네스 고정점 검증)

| 실험 | F_τ | 의미 |
|---|---|---|
| 같은 명령을 그대로 재배포 | **2.5%** | 기계 바닥 (수치 잡음 하한) |
| 실현 궤적을 q_des로 재배포 ("소박 배포") | **64.7%** | 함정 — 저감쇠 PD가 자기 궤적을 다시 쫓으며 공진 재증폭 |

- 비유: 노래방에서 자기가 부른 노래의 녹음을 다시 따라 부르면 박자가 밀리는 것과 같음 —
  "결과"를 목표로 주면 안 되고 "명령"을 목표로 줘야 한다.
- 이것이 "개루프 최적 ≠ 폐루프 최적" (철칙 10)의 최초 정량 재현. 모든 배포 채점은 이 2.5~65% 눈금 위에서 읽는다.

## 4. 6가지 최적화 방법 (Phase A/B/C)

| 방법 | 무엇인가 (비유) | h_plan | 특징 |
|---|---|---|---|
| OL-CMA | 토크 악보를 통째로 진화탐색 (지휘 없이 녹음 재생) | 1.251 | 천장 라이딩 22~44% |
| MPPI | 매 순간 수백 가상 미래를 굴려 평균 (실시간 바둑 수읽기) | 1.018 | 온건, 클립 여유 |
| CL-CMA | **PD를 통과한 결과**를 직접 점수화 (가수 목소리에 맞춘 작곡) | **1.517** | 바운스 펌핑 — 측정 dq 범위 밖 |
| iLQR | 트윈 원본 기울기(mjd_transitionFD)로 국소 최적화 | (수확 대기) | 대리모델 없이 정확한 트윈 미분 |
| NLP | 해석적 등가 2링크 + 측정 법칙층 내장 CasADi collocation | 1.128→트윈 1.077 | 교차검증 격차 −4.8% |
| PPO | 트윈에서 시행착오 학습 (RL 파일럿) | 1.319/1.349 | 942k 스텝, 3.3분, 보상설계 민감 |

- 전 방법이 실측 0.98 초과 → **헤드룸 명제 재현** (hip 8~14 rad/s 미개척 대역이 원천).
- PPO 보상설계 교훈: v1(순간 상승 보상)은 착지 시 상쇄되어 h≈0.54 국소최적에 갇힘 →
  v2(러닝맥스 증분: 보상 총합 ≡ 최고점 도달 높이)로만 1.3m대 진입. RL은 목적함수 문장 하나에 민감.

## 5. 배포 리허설 (Phase D) — 4가지 배포 전략의 지형도

### 5.1 그대로 PD (q_des = 계획 상태)
- 개루프 계획(OL-CMA/NLP): h는 나오지만 **F_τ 98~110%** — 계획 토크와 무관한 토크로 뛴 것.
- CL-CMA[설계게인]: **F_τ = 0.0%** (자기 게인에선 고정점 — 설계상 완벽) but mid 게인으로 바꾸면 23.8%.

### 5.2 기준 성형 (q_des = q_plan + raw*/kp)
- 원리: PD 식 τ=kp(q_des−q)에서 로봇이 계획대로 움직일 때 정확히 raw*가 나오도록 목표각을 미리 밀어둠.
  (피드포워드를 목표각에 인코딩 — 스프링을 미리 당겨두는 것과 같음.)
- MPPI: 70% → **6.2%** 대성공. 천장 라이딩 계획(NLP/OL-CMA)은 실패 (오프셋 0.3rad + 클립 포화).

### 5.3 FF+PD (실기의 기존 채널 — desiredTorque = τ*_raw 직접 주입 + PD 보조) ★권고
| 계획 | h_PD | F_τ |
|---|---|---|
| **PPO(best)** | **1.352~1.362** | **4.0~4.6%** |
| MPPI | 1.03 | 4.7~4.9% |
| NLP [mid] | 1.203 | 19.1% (98.9%→구제) |
| OL-CMA [mid] | 1.264 | 27.6% |
- 0422/0319tau/0324 세션이 실제로 쓰던 명령 구조 그대로 — 새 펌웨어 불필요.
- 고게인+FF는 이중 주입 충돌 (NLP high 98.9%) → 게인-계획 매칭 필요.

### 5.4 폐루프 인식 최적화 (이론 최강, 단서 있음)
- F_τ=0은 설계게인 한정. 전략이 측정 신뢰영역 밖 (바운스 펌핑, dq 45 rad/s).
- 신뢰영역 재최적화: (수확 대기 — 1~2차는 과잉 제약으로 h 0.745 정직 기각)

## 7. 실기 배포 권고안 (콜아웃)

1. **궤적**: 트윈 PPO(best) 또는 MPPI (온건·클립 여유·바운스 없음)
2. **채널**: FF+PD — desiredTorque = τ*_raw, (q_des,dq_des) = 계획 상태, mid 게인
3. **트윈 예측**: h ≈ 1.35m (실측 최고 +0.37m), F_τ ≈ 4% (기계 바닥 2.5% 근접)
4. 실기에선 여기에 모델 오차(P24 잔여)가 가산 — 1차 기대치는 보수적으로.

## 8. 정직 노트

- PPO h_plan 비교의 비대칭: 관절범위 하드 종료 vs Phase A 소프트 페널티.

- 이 전부는 트윈 안 리허설 — 실기 검증이 다음 단계.
