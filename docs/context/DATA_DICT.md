## 데이터 사전 (핵심 함정)
- **`hip2/knee2/GRF2.xlsx` (07-29+, 점프 계열 전 세션)**: 전 구간(앉기~착지 안정화) 확장판 — **전 세션 rad 통일**·
  500Hz·기존 창 오차 0 포함·토크 언랩·각도 랩 없음. 채점/캘리브는 *2 우선. 파서 = `goal23_fullspan/fs_data.py`.

- `hip.xlsx/knee.xlsx`: currentAngle/desiredAngle/currentAngleVelocity/desiredAngleVelocity/currentTorque/desiredTorque
- **currentTorque = 모터 명령 토크, 단위는 `N·m`** (사용자 정정 08-08 + AK80-9 매뉴얼 확인:
  `T_MIN=-18, T_MAX=18; t_int=float_to_uint(t_ff,T_MIN,T_MAX,12)` · 사양표 N.M 행 −18~18).
  구 표기 "raw iTM 단위 (Nm 아님!)"는 **오기**. 편의상 raw 라 불러도 값 자체는 N·m 이다.
  12bit ±18Nm 랩 → MATLAB 언랩본 (그래서 |값|>18 이 나온다).
  ⇒ a_hat·정본곡선은 **단위 환산이 아니라 "명령 대비 실제 축토크 비율"(캘리브레이션)** 이다:
  a_hat ≈ 0.58× (전 구간 일정) · 정본(분동) 1.26×(저토크) → 0.86×(고토크).
