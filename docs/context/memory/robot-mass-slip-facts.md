**사용자 실측 (2026-08-02 확인)** — 트윈 정합의 기준값. 추정치로 대체하지 말 것.

- **로봇 총질량 = 3.26 kg** (케이블 제거 상태). 정합 시 **3.26~3.3 kg 범위 허용**.
  트윈 정본 XML은 **3.201 kg**로 60g(1.8%) 가볍다 → `FS_MASS=<kg>` env로 base 바디에 부족분 가산
  (링크 질량·관성은 불변). 점프높이는 같은 에너지에서 h ∝ 1/m 이므로 −1.8% 방향.
- **발 플레이트(접지판) 길이 = 120 mm** — 영상 슬립 측정의 실물 자로 쓸 것 (벽 줄자보다 발과 같은
  깊이라 원근 왜곡이 적다).
- **26.07.23/150_2.2_250_3**: **딥스쿼트(앉는) 구간에서만 발이 8~10mm 미끄러진다** (사용자 육안).
  이륙 즈음에는 발이 훨씬 크게 움직인다. 현행 트윈(fs16)의 같은 구간 미끄럼은 −5.2mm로 **약 절반**.
  → 하강 구간 슬립 부족이 확정된 결손. [[foot-rolling-vs-slip]]
- 주의: 영상 슬립을 잴 때 **하강 구간만 재지 말 것**. 이전 분석이 하강만 재고 "판별 완료"로 보고한
  전례가 있다 (push 구간은 24fps로 불가하다는 옛 결론을 재검 없이 승계한 오류 — 실제로는 30px 이상
  움직여 판독 가능).
