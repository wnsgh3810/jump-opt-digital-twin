## ★결과 (2026-07-22 실기 5게인 스윕 — 26.07.22/) — 배포 성공 + 토크분배 뒤집힘

pd15 미끼를 5게인(60_0.75~150_3.3_500_5)에 순수 PD 배포. **점프 성공: 실제 h 0.74~0.85m
(게인↑ 단조증가), 트윈 예측 0.76~0.85m — 높이 ±8~10cm 일치.** 미끼 추종 확인 (hip/knee
desiredAngle = pd15 미끼 정확). **파이프라인(트윈→최적화→CL 순수PD 배포) 실증 성공.**

★핵심 미스매치 = **토크 분배가 뒤집힘 (α 문제 아님, dynamics)**:
- **실제 knee 축토크 ~20.5Nm에 포화 (raw 37, 전 게인 평탄)** — knee 모터가 매 점프 맥스아웃.
  트윈은 knee 15.6~19.3Nm (게인↑에 감소). 실제 knee가 계획(15Nm)·트윈보다 ~30% 더 씀.
- **실제 hip 축토크 ~8~10Nm (거의 놀음)**. 트윈은 hip 12~17Nm 포화 기대. 반대.
- 즉 **실제 = knee 지배(포화)+hip 유휴 / 트윈 = hip·knee 균형.** 총합 비슷해 높이는 맞음.
- 실제 knee가 트윈보다 느리게 움직임(명령 랙 큼)=knee 유효관성/부하 과소모델. raw 평탄포화 =
  단순 게인(α) 스케일 아님 (게인 무관 포화).
- 높이 게인추세도 반대: 실제 게인↑→높이↑(0.74→0.85), 트윈 ~평탄/감소.

★함의: τ-fidelity 미달 (knee 20 vs 계획 15, hip 8 vs 계획 14). 다음 = 트윈 정밀화
(**knee 부하/관성 ↑, hip 기여 ↓**) 후 재최적. knee 실측 천장 ~20Nm(raw 37)이므로 캡 15→20
올리면 더 높이 가능. 분석 그래프 graphs/REAL_gain_sweep_summary.png · REAL_vs_twin_150_3.3_500_5.png.

## ★개선 (07-22 후속) — 단위 정정 → α=0.5 regime, 2차 계획 v2a05

★**단위 함정 (사용자 지적)**: Real Data.txt "절대 기계적 에너지"는 raw currentTorque로 계산(∫|raw·dq|)

"구조적 결손" 결론은 유령이었음. **실기 로그 에너지는 반드시 ∫|a_hat(raw,dq)·dq|로 재계산.**

★**개선 진단 (재식별)**: 무릎 부하(댐핑/관성) 증가는 Mode A 재현 깸(0602 dq2 1.29→4.37 — 측정토크 주입에
댐핑 더하면 무조건 나빠짐, 무릎 실마찰=baseline이 맞음). tm(지연)은 Mode A 무관(SD만 씀)이나 단독으론
lag 부족. **해답 = 배포 regime α≈0.5 (hip·knee 실효게인 = 라벨의 절반)** — 5게인 a_hat목표에 공동fit
오차 2.52(에너지·lag 추세 포착). α는 세션별 α처럼 커맨드층 regime특정 + **Mode A 무관 = 학습 호환**.
물리해석: 공격적 배포 bait에선 실효게인이 라벨보다 낮음(펌웨어 α_kp ramp). 힙 약화→무릎 더 일→포화.

★**2차 계획**: `t0nc_cl_v2a05.npz` = CL을 α=0.5·게인150/3.3/500/5·클립35.5로 재최적 (t0nc_cl_pdrep.py
