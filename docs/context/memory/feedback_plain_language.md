사용자가 반복 지적 (2026-07-13 세션에서 3회+): "너만 아는 용어 사용하지 말고 풀어서 설명해 **항상**", "이해하기 쉽게 보고해", "쉽고 간단하게 설명해".

**Why:** 내가 세션 중 만든 코드네임/약어(창 점수, λ*, pre30, CL, mshoot, G6 등)는 사용자에게 정의 없이 통하지 않음. 사용자는 로봇공학 전문가지만 **내 내부 명명은 모른다** — 전문성 문제가 아니라 명명 소유권 문제.

**How to apply:**
- 새 용어/점수/지표를 처음 쓸 때마다 한 줄 정의 병기 (예: "창 점수(=실측 토크를 넣고 0.2초씩 재생했을 때 움직임 재현 오차, 낮을수록 좋음)")
- 표/보고에 숫자를 쓰면 그 숫자가 "무엇을 재는지"를 같은 문단에서 설명
- 비유 우선, 수식은 그다음 (노션 표준 PLAYBOOK §10과 동일 원칙 — 대화 보고에도 적용)
- 이전 턴에서 정의했더라도 몇 턴 지나면 다시 짧게 상기
- **(07-28 재지적: "e1~â1, k̂, τ/k̂ 보정 이게 뭔지... 너만의 용어 쓴거 다 용어 정리해줘 이해하기 힘들어 항상")**
  수식 기호(â, k̂, e1~x 회귀 표기, 풀드 등)도 예외 아님 — **분석 보고 전에 기호 등장하면 그 자리서 괄호 정의,
  긴 분석은 용어표를 먼저**. 노션 페이지엔 용어 사전 섹션 추가가 표준 (EXP5 ⑯절 참조 패턴).
