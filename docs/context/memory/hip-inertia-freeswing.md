**26.08.07 `no_current`/`no_current2`** = 사람이 다리를 들었다 놓기를 스무 번쯤 반복한 기록
(긴 자유 진동이 아니다). 여기서 **손을 뗀 뒤 반대편까지 가는 시간**을 시뮬과 맞대어
힙 모터축 회전 관성을 쟀다. 답 **0.0164** (큰 폭 스윙만 쓰면 0.0145~0.0193). 현행 0.010.

**Why 이 방법이 유효한가 (08-12 낮의 무효 판정을 피한다):** 모터가 꺼져 있어 **무시할
토크가 없다** — 어제 퇴화의 정체("토크 무시하고 등속 미끄러지기")가 원리상 불가능하다.
자유 진동은 관성을 키워도 폭이 안 줄고 느려지기만 하므로 "관성↑→덜 움직여 오차↓"도 없다.
검산: **힙 마찰을 0으로 놓아도 0.0153** → 마찰이 관성인 척하는 것이 아니다.

**실험 조건 (사용자 확인 08-12):** 몸통 = 매달고 제대로 고정 · 무릎 = **붙잡은 게 아니라
자유**인데 마찰로 안 움직임(실측 0.01도) · 놓을 때 손 완전히 뗌.

**How to apply:**
- 작은 폭 스윙(<40도)은 **쓰지 말 것** — 마찰로 조기 정지해 시간이 짧게 측정된다.
  (시뮬에서는 아예 반대편에 도달을 못 한다.) 폭 의존은 무릎 각도 탓이 아님을 확인했다.
- 관성을 올리면 **폐루프만** 나빠진다(+1.2~2.8%). 측정 토크 주입 재생은 +0.05%로 무해하고
  점프 높이는 −0.84%로 오히려 좋아진다 ⇒ **물리와 충돌하지 않는다.**
- 그러므로 관성만 따로 올리지 말고 **12번째 축으로 넣어 재적합**할 것. 상쇄 후보는 힙
  속도비례 저항과 힙 명령 지연(둘 다 기존 축). [[quasistatic-is-lower-bound]]와 같은 구조 —
  한 값이 다른 것의 결손을 대신 떠맡고 있다.
- 코드 `code/goal23_fullspan/_GHI_freeswing.py` (`checks` 인자로 검산까지).
