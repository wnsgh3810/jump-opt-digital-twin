2026-08-14 확정. 사용자가 비교 그림을 보고 "H3·H4와 거의 안 달라졌다"고 지적해 성분 분해로 확인.

**5회차 탐색 30,720회 · 488분이 점프 예측에 기여한 것은 0이다.**
같은 채점판에서 4회차 승자 vs 5회차 승자:

| 성분 (0이 완벽) | 4회차 | 5회차 |
|---|---|---|
| 점프 4성분 (주입·폐루프각·폐루프토크·높이) | — | **전부 0.1~7.6% 나빠짐** |
| 매달림 15건 (신규) | 1.3553 | 0.7676 (−43%) |
| 짐 지고 일어서기 4경우 (신규) | 3.1628 | 2.2950 (−27%) |
| 총점 | 0.66647 | 0.49943 |

개선 0.1671 = 100% 신규 두 성분. 점프는 오히려 +0.0020 나빠졌다.

**원인 = 상쇄.** 값은 크게 움직였는데(무릎 건마찰 ×3.7, 힙 속도비례 ×38) 점프 예측은
±3% 이내. 마찰이 커진 만큼 명령→축토크 환산 천장이 깎였다(무릎 4.12→2.85, 힙 2.37→1.87).
점프 창만으로는 "저항 크고 토크 크다"와 "저항 작고 토크 작다"를 갈라낼 수 없다.

**Why:** 점프는 밀어내는 짧은 고토크 구간이 지배해서, 마찰과 토크 크기가 같은 방향으로
합쳐진 하나의 양으로만 보인다. 두 성분을 가르려면 **저속·저토크 구간**(매달림 흔들림,
무동력 세션)이 필요하다 — 거기선 마찰만 남는다. [[quasistatic-is-lower-bound]] ·
[[torque-map-flat-vs-measured]] 와 같은 뿌리.

**How to apply:**
① **점프 축을 더 훑지 말 것 — 낭비가 증명됐다.** 6회차는 판별 정보(저속 구간)를 점수에
   더 싣고, 일어서기 원인축(하중 비례 손실·자세 의존 지렛대)을 직접 넣는다.
② 얻은 것 하나: 무릎 건마찰이 매달림 실측 0.423 근처(0.438)로 이동했다. 점프 정확도를
   한 자리도 안 잃고 값이 실측으로 갔으므로 **같은 성적을 더 옳은 값으로** 내게 됐다.
   외삽에서만 차이가 나는 종류의 개선이고 실제로 그렇게 나왔다.
③ 절대 수준은 여전히 실패 — 매달림 0.768·일어서기 2.295 는 "못 쓴다" 선(0.43~0.53)의
   1.4배·4.3배 바깥. "쓸 수 없음 → 여전히 쓸 수 없음" 이다. 승격 보류가 옳다.
④ 총점만 보면 25% 개선으로 읽혀 오독한다. **새 성분을 판에 넣은 회차는 반드시 성분별로
   쪼개서 볼 것** — 총점 비교는 판이 바뀌면 무의미하다. [[score-composition-vs-final-goal]]
