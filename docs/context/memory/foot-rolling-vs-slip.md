**사실**: 트윈·실물 모두 발은 둥근 롤러(실물 r≈19~20mm 영상 실측, 트윈 실린더 r=21mm)라
하강 중 발 중심이 **구름만으로 +5~9mm** 이동한다 (마라톤 D P13이 "전 세션 균일 5.7~6.9mm =
rolling 기하 이동, 슬립 아님"으로 최초 판정). **발 이동량을 '슬립'이라 부르면 안 된다** —
진짜 미끄럼은 접촉 물질점 접선속도(`FS_SLIPLOG=1`, mj_jac@qvel) 적분으로 재야 한다
(`_E_slipdecomp.py`). 발 x는 관절각의 민감 함수(1°≈7mm)라 mm 슬립 비교는 각도 오차와 같은 자릿수.

**Why**: 마라톤 E에서 이 구분을 잊고 발 이동을 슬립으로 명명했다가 사용자 적발로 소급 정정
(E 로그 P12 추록). 컨텍스트 압축 2회로 D-P13 판정이 요약에서 탈락한 것이 경위. D_slip 판별은
슬립날−무슬립날 차분이라 구름 상수가 소거돼 결론은 생존했지만, 서사가 오염됐었다.
같은 계열: 마라톤 A H5 잔여 큐에 "구름 차감 슬립 재측정"이 이미 예약돼 있었다.

**How to apply**: ①새 마라톤에서 지표를 정의하기 전, 같은 관측량을 다룬 **직전 마라톤 로그
(MARATHON_*.md)를 재독**한다 — CURRENT_STACK·REJECTED만으로 부족 ②판정에 쓰인 분석은 인라인
heredoc 금지, 파일로 저장 (E-H2 영상 대조 스크립트 유실 교훈) ③슬립 수치는 반드시 slipv
(물질점) 기반으로 보고하고, 발 이동 기반이면 "이동(구름 포함)"으로 명기. [[marathon-e-slip-260802]]
