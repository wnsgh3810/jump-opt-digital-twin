발끝에 정확한 무게추 0/2/4kg 를 매달고 천천히 왕복시킨 데이터(`26_08_07/*/probe_sweep_v1`)에서,
**같은 자세를 올라갈 때와 내려갈 때 명령의 절반차 = 마찰**을 뽑으면:

- **무릎: 마찰 = 0.135 + 0.1197·|하중|  → 전달효율 88%**  (2kg +0.1169 vs 4kg +0.1177, 0.7% 일치)
- **힙  : 마찰 = 0.278 + 0.0029·|하중|  → 효율 ≈100%**

무릎만 4절링크+벨트를 거치고 힙은 모터가 허벅지를 거의 직접 돌리는 구조와 일치한다.
도약(명령 35)이면 무릎 마찰이 4.3 = 매달림 시험(0.1~0.5)의 10배.

**Why:** 마라톤G 는 이 왕복 데이터에서 상행·하행을 **평균내어 마찰을 지우고** 중력만 봤다.
지운 그 성분이 오늘 필요한 값이었다. 이미 있는 데이터에서 **버려진 성분**을 되찾는 것이
새 실험보다 빠를 때가 있다.

**How to apply:** 이 88%/100% 는 **준정적 사실**이고 부정되지 않았다. 그러나 이것을
"명령에 비례하는 손실"로 **고속까지 외삽한 모형은 두 번 다 기각됐다** (REJECTED #82 양채널·
#83 무릎전용). 데이터는 고토크에서 **포화**를 고른다 — 지배적인 것은 마찰이 아니라 전압·
역기전력에 의한 **한계**다. 재심은 포화형(`canon_env`)과 결합해서만. [[quasistatic-is-lower-bound]]
