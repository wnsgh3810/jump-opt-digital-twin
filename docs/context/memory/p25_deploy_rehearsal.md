# P25 배포 리허설 (2026-07-17, p24a 트윈 위) — 완료

**최종 권고 (실기 배포)**: 트윈 PPO(best) 18Nm판 궤적 + **FF+PD 채널** (desiredTorque=τ*_raw,
(q_des,dq_des)=계획, 실기 0422 세션 구조 그대로) → 트윈 예측 h 1.257m (실측 최고 0.98 +0.27m),
F_τ 3.4~4.2%, 모터 스펙 18Nm 준수. 다음 단계 = 실기 FF+PD 배포 실험.

핵심 사실 (재유도 어려운 것만):
- **토크캡 번역**: 축 18Nm(AK80-9 V2 피크) ⇔ **raw 클립 31.1771** (a_hat 운동방향 가지 정확히 18.00Nm;
  35.5→20.23Nm 보고 규약과 동일 가지). raw≤18로 걸면 실제 ~11Nm (단위 혼동 — 사용자 문답으로 확정).
- **a_hat 위상 (사용자 문답 2회로 확정)**: 해석 전용 아님 — 실기 온보드 PD(raw)→a_hat→관절이므로 폐루프
  시뮬 안에도 필수. 실증 = 로그 raw=폴더게인 PD 출력(펌웨어 보상 없음) + Mode A 재현. 사용자 그림
  (모델·최적화·채점 전부 â/Nm 공간)은 구현과 일치 — F_τ가 â vs τ* 그 자체.
- **철칙 10 정량 눈금**: 고정점 재배포 F_τ=2.5%(기계 바닥) / 실현궤적 재배포 64.7%(공진 재증폭) —
  전 배포 점수는 이 눈금 위에서 읽음.
- **FF+PD 게인 무감** (핵심 발견): 실 세션 게인 8종(60_1.5~150_2.2_500_4) 중 7종에서 PPO F_τ 3.4~4.6%
  (60/1.5에서도 3.9~4.2). "그대로 PD"는 전 게인 80~110% 낙제, 성형은 온건 궤적만 구제(천장 계획 실패).
  **예외: 150_2.2_350_3.5만 두 캠페인 공통 F_τ 2배 튐 (7.5~9.4%, 미규명 — 실기 배포 시 회피).**
- h_plan 서열 (20.2→18Nm): iLQR 1.542→1.388 / CL-CMA 1.517→1.388 / PPO 1.349→1.246 / OL-CMA
  1.251→1.148 / NLP 1.128→1.070(트윈갭 −4.0%) / MPPI 1.018→1.077(천장 비구속이라 캡 무관). 캡 비용
  −5~−10%, 이륙 타이밍 불변(토크 프로파일로 흡수). CL-CMA F_τ=0.0%는 설계게인 한정 고정점.
- PPO 보상설계 민감: Δbz shaping은 착지 상쇄로 h≈0.54 국소최적 — 러닝맥스 증분(합≡apex)으로만 탈출.
  골든 = cl_run23 비트일치. 신뢰영역 CL판은 과잉 제약(h 0.80)으로 미완 기각.

  결과 원장 p25_e_master[_t18].json, 교차 p25_e_cross_table.md. 노션 P25 페이지 (GOAL22 허브 아래,

  엄격 사영 실비용 −0.14cm (iLQR 유효 실증, p25_a4_ilqr_t18_strict.npz). ★교훈: **정책(RL) 궤적의

- **task0 캠페인 (07-18, `code/goal22/p25_task0/`)**: 사용자 지시로 제약을 AVT task0으로 교체
  (|â|≤15Nm=raw 25.5810·T-N −0.731/48.48·각도박스·dq50·시작자세 자유). 결과: **CVT l_i=25.08

  no_cvt 활성 제약은 무릎 15Nm 단독(T-N 논바인딩). **OL-CMA+FF+PD 2.6~4.1% (8게인 전부)** —
  온건 계획은 개루프 기록도 완벽 배포, 최적 게인 = 최연약 60_1.5. PPO는 각도 하드종료에서 0.699

- **l_i 상수 최적화 (07-18, 4방법)**: **트윈 최적 l_i ≈ 26mm (25~28 고원, CL-CMA 자유 26.25/1.123m)**

  저평가 — 진단 완료), PPO 고정-l_i "30 최고"는 저예산 아티팩트 (같은 26에서 조건부 0.957 >
  고정 0.688). l_i는 점프당 상수 (동작 중 고정 — l_i 고정≠변속비 고정, TR은 자세 연동 20→15).

- **성형 순수 PD = 최종 목적의 실현법 (07-18 확정)**: q_des = q_plan + a_hat⁻¹(τ*)/Kp 성형이면
  **FF 채널 없이 실기 위치모드만으로 τ≈des** — task0 캠페인에서 CL 4.3%/OL 6.0% (8게인 강건).
  성형 순수PD ≡ FF+PD 대수 동일 (차이는 tm 필터 1회 = 3→6%) → 모델오차 민감도 동일, 잔차
  τ-갭=Kp·e가 헌법 지표 그대로. 단 ① NLP는 게인 민감 (일부 게인 101% — 90_1.5 고정 필요)
  ② RL 계획은 raw* 지터 때문에 성형 23% vs FF 3.5% — 지터 계획은 FF 우위. ③ 비성형 순수 PD가
  낙제(66~90%)인 건 최적화 잘못이 아니라 범주 착오 (상태 궤적≠PD 명령; PD는 오차=토크 필요).
  ④ 고게인 스터디: 순수 PD의 des-추종 회복은 kp 수천(MIT 인코딩 상한 500 밖)에서만; FF+PD는
  게인↑ 시 역효과 → 무른 게인 권장. ⑤ a_hat 판별 (사용자 3회 문답): 실측 0602 재현이 a_hat
  포함 체인만 성립 (제거 시 3배 붕괴) — a_hat은 해석 전용 아니라 루프 내 물리로 최종 확정.
