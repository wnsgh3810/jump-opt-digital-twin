코드를 수정하거나 새 파일을 만든 후, 자동으로 커밋하고 "커밋했습니다" 정도로만 알려줘.

**Why:** 매번 물어보는 게 번거로움. 자동으로 하고 결과만 알려주는 게 효율적.

**How to apply:** 코드 변경 완료 후 바로 git add + commit. 커밋 메시지는 변경 내용 요약으로. 사용자에게는 간단히 알림만.
