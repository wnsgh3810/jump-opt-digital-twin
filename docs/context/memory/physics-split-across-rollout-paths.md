폐루프(PD 제어)와 개루프(측정 토크 주입 재생)는 **구현이 별개 함수**다. 그래서 한쪽에만
들어간 물리가 생긴다. 그런 결손은 **폐루프에서는 안 보인다** — PD가 오차를 되받아 메우기
때문이다. 개루프에서만 터지고, 그때 나오는 숫자는 "물리가 틀렸다"처럼 보인다.

실제 사례 (08-12): 변속기 링크의 전달 손실(`cvt_diss`)이 `rollout_cl_fs`에는 있고
`rollout_ol_fs_b`에는 없었다. 변속기 무릎각 오차 17.86° → 손실을 넣자 **4.27°**.
같은 날 폐루프 성적은 멀쩡했다(기준선 대비 −5%).

**Why:** 층을 새로 추가할 때 한쪽 함수에만 넣고 끝내는 일이 반복된다. 이 저장소는
개루프/폐루프가 문자 미러 관계라 "한쪽에 있는 훅이 다른 쪽에도 있는지"가 검산 가능하다.

**How to apply:** 새 물리 층을 넣거나, 어떤 데이터가 유독 한 판에서만 크게 틀릴 때
→ **먼저 `ft.get("...")` 류의 훅이 두 경로 모두에 있는지 grep 한다.** 물리를 의심하기 전에.
크기 차이가 "일관되게" 크다는 것은 물리의 증거가 아니다 ([[measurement-vs-computation]]).
채점 코드부터 읽는 습관은 [[relative-gates-miss-absolute-failure]]와 같은 계열이다.
