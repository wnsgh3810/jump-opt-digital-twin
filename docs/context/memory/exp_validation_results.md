## 핵심 발견
1. **P200 위치제어가 시뮬레이션에 가장 가까움**: ImpR=1.042, ER=0.995, GRF peak 117N≈sim 118N
   - 하지만 점프 높이 0.79m로 가장 낮음 (마찰 손실이 실제로 존재)
2. **토크제어: Knee 토크 추적 매우 우수** (Pearson r=0.87~0.92)
   - Knee err 4~5° (위치제어의 14~29°와 비교)
   - 하지만 GRF가 desired보다 낮고 (0.73~0.75배) 점프 높이도 낮음 (0.71~0.74m)
3. **토크제어에서 dq2 peak가 28 rad/s** (desired 21.5보다 30% 높음)
   - 토크 ref를 잘 따라가지만 속도가 더 빠름 → 접촉 컴플라이언스의 spring release 효과
4. **위치제어: PD 게인 낮을수록 추적 오차 크지만 점프 높이 높음**
   - P60: err=29° but h=0.86m vs P200: err=14° but h=0.79m
5. **E/(Imp)² 분석**:
   - 위치제어: 0.90~1.02 (P80, P90, P100에서 ≈1.0)
   - 토크제어: 1.12~1.23 (1.0보다 높음)
6. **에너지 누적: 전체의 75%가 마지막 15% 구간에서 발생**
