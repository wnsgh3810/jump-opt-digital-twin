2026-08-14, 연구 최종 지표를 처음으로 직접 쟀다. 26.07.27 은 최적화 계획이 실기에 배포된
유일한 세션이고, 계획 파일은 `code/goal22/p25_task0/t0nc_cl_v9.npz` (계획 축토크 τ*·명령
토크·목표각 스플라인·게인 포함). 7개 trial 전부 같은 계획의 이륙+10ms 절단본을 기계
정밀도(목표각 RMSE ~1e-6°)로 배포했고, 계획 게인과 일치하는 본 시행은 150_2.2_250_3.

결과 (이륙까지 창, 명령 수준, qd 4ms 스큐 보정 정렬):
- **무릎: 상대 RMS 28%, 상관 0.80** — 근접. 단 실측 파형이 계획보다 ~10ms 선행.
- **힙: 상대 RMS 46%, 상관 0.97, 피크 실측 37.2 vs 계획 24.9 N·m = 1.49배 초과.**
  파형은 맞고 크기가 초과 — 초과분은 게인 비례 (kp100 0.24 → kp250 0.56)
  = "토크 오차는 각도 오차의 게인 증폭"(VERDICT §6-3)의 최종 지표판 확인.
- 과거 exp5 의 무릎 0.144 는 교차상관 정렬 -8ms 편차의 산물 (정밀 정렬 0.272) — 2배 낙관.

**Why:** 최종 목표를 재는 자가 이제 실존한다. 힙을 고치려면 토크맵이 아니라 폐루프 각도
오차(파형 모양)를 고쳐야 한다는 것이 최종 지표에서도 확인됐다.
**How to apply:** 다음 배포 전 반드시 이 판으로 재라 (스크립트 계보: 임시폴더
tau_fidelity_0727_v2.py — 정식화 필요). 정렬은 배포 명령 채널 기계정밀 정렬만 신뢰
(교차상관 정렬 금지). 이륙 후 계획은 배포된 적 없어 비교 원리상 불가.
