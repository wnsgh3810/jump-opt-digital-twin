# 슬립·구름 trial별 표 (2026-08-09 · 55 trial 전수)

> 이 파일은 `_G99_trialtable.py` 가 생성한다. 손으로 고치지 말 것 — 측정이 갱신되면 `_G79_collect.py` 가 다시 쓴다.

부호: **+ = 화면 오른쪽 = 모델 +x** · 단위 mm

```
슬립 = Δx(영상) − r·Δθ(엔코더),   r = 20.0 mm
자   = 발 금속판 30.0mm / 측정 지름[px]  (영상마다 재측정)
```

★ **슬립 열은 전부 구름을 뺀 값이다.** Δx·구름 열은 그 성분이다.
```
검산:  하강슬립 + 바닥슬립 + 푸시슬립 = 전체슬립
       전체Δx − 전체구름            = 전체슬립
```

열 설명
- **Δx**: 영상이 본 발의 실제 이동 · **구름**: 엔코더가 말하는 굴러간 양 · 둘의 차가 **슬립**.
- **구름+슬립**: 정의상 **Δx 와 같다** (slip = Δx − roll). 눈으로 검산하라고 넣은 열이다.
- **크기합** = |구름| + |슬립|. 둘의 **부호가 반대면 Δx 보다 훨씬 크다** — 발이 굴러간 만큼 못 가고 그 차이를 헛돈 것이다(휠스핀). 55 trial 중 **34건**이 이 경우다.
- **푸시슬립 극값**: 푸시 구간 **안에서** 슬립이 간 최소~최대. 끝점차와 크게 다르면 구간 안에서 갔다가 돌아온 것이다 (24fps 정렬 한계의 서명).
- **sens**: 영상-데이터 동기가 ±1프레임 어긋날 때 푸시 슬립이 흔들리는 폭. **작을수록 신뢰**.
- **절단**: 접지 구간을 어디서 끊었는지의 사유 (점수붕괴 / 이륙(위로) / 물리한계Δcx / 아래드리프트).
- **QC**: 경고 개수. 0이 최선.
