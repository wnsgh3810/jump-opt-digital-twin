# MARATHON_SEA — 디지털 트윈 대수술: 숨은 스프링(hip 직렬탄성) 도입 + 다과제 일반화

## 배경 (exp5 마라톤의 발견 — 이 마라톤의 출발점)

exp5(26.07.27, hip 7게인 스윕) + 영상 검증 + Mode A 검증 + 교차-세션(7일치)으로 **삼중 수렴 확정**:

> **hip 액추에이터와 사지 사이에 직렬 탄성(비틀림 스프링) k_s ≈ 160±20 Nm/rad가 실재한다.**
> ① α 램프 적합: α=k_s/(kp+k_s), k_s=150 (배포 CL 관점, 7게인 1-파라미터)
> ② Mode A e1~â1 회귀: k̂ 풀드 166, r +0.87~0.92 (플랜트 관점) — 보정 후 hip 4~5°→1~1.6°
> ③ FK 가짜슬립(3mm/Nm) + 영상 반증(진짜 슬립 ≤14mm) (기하 관점)
> 교차-세션: 배포 5일(07-22~27) 전부 재현 (16/19 r>0.7, k̂ 중앙 ~170). 저게인 k̂ 93~122 =
> 저부하 연화(비선형) 힌트. fit 세션(0424/0602)은 보정층이 흡수/과잉보정(현상 vs 물리 판별 완료).

파생 확정: 트윈 접촉 물리 무죄 (트윈 발중심 −13.8mm = 실물 영상 10~17mm 일치, 슬립 DOF 불필요).

## REJECTED 재심 사유 (철칙: 재시도 전 명기)

- **#28 링키지 탄성** — 재심 조건 "벤치에서 실측 강성 확보 시" **충족** (in-situ 3중 측정 k_s≈170).
- **#10 기어박스 SEA·#21 벨트 SEA** — 기각 근거가 "fit 세션 채점"이었는데, 이번에 fit 세션에선
  보정층이 스프링을 흡수해 신호가 안 보임을 입증 (0424 r 음수 = 과잉보정). 기각의 증거 기반 무효화.
  또한 당시 구현(로터 DOF+텐던, 동역학 내부)과 달리 이번 1차 구현은 **측정·제어 인터페이스면**
  (인코더=모터측)이라 실패 양식이 다름.
- **#11 hip 스프링(병렬)** — 별개 물리 (병렬 스프링=정적 토크 발생, 직렬탄성=정적 토크 0). 재심 불요.
