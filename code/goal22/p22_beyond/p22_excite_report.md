# P22 여기 궤적 설계 보고 — 30분 공중(레일 현수) 시스템 식별 세션

생성: p22_excite_design.py (seed=22, QUICK) · 기준 모델: P19 FINAL 후보 (fourbar_p19_candidate.json) · Phase 1 기계 재사용

## 1. 무엇을 왜
- 목적: 로봇을 레일에 매달아 발을 띄운 채(공중), PD로 아래 궤적을 30분 반복 추종시켜
  관성·마찰 파라미터를 **접촉 없이** 식별할 데이터를 얻는다.
- "잘 보이는 정도"의 지표 = 스택 회귀자의 최소특이값 σ_min: 토크 노이즈 0.4 Nm 대비
  가장 안 보이는 파라미터 조합의 신호 크기. σ_min이 클수록 모든 조합이 고르게 식별됨.
- 조건수 cond = σ_max/σ_min: 제일 잘 보이는 조합과 제일 안 보이는 조합의 비율(작을수록 균형).

## 2. 궤적 정의 (CSV 규약)
- 파일: `p22_excite_traj.csv` — 열 `t,q1_des,q2_des,dq1_des,dq2_des`, 100 Hz, 1주기 10 s (1000행). 로봇에서 **그대로 루프 재생** (주기 경계 연속, 시작/끝 속도 0).
- **좌표 규약 = 측정(xlsx) 규약** (jump_0602 세션과 동일, 오프셋 0):
  hip: `q1_meas = −q1_model − π/2`, crank(무릎모터 채널): `q2_meas = −q2_model`.
  즉 CSV 값은 hip.xlsx/knee.xlsx의 currentAngle/desiredAngle과 같은 단위·부호(rad).
- 시작 자세 = CSV 첫 행. 재생 전 로봇을 이 자세로 천천히 이동시킨 뒤 루프 시작.

## 3. 하드 제약 (구성적으로 보장 + 전 샘플 검증)
- 관절범위: fit 세션(l_i=30mm: 0421/0424/0602) 실측 방문범위에서 스팬 5%씩 양쪽 축소 → 모델좌표 hip [-1.297, -0.283] rad, crank [+0.554, +2.551] rad.
  (0429는 CVT l_i=25.08 세션이라 크랭크↔무릎 관계가 달라 envelope에 미포함, 정보로만 채굴)
- 속도 |dq|: hip ≤ 8, crank ≤ 12 rad/s · 가속 |ddq| ≤ 200 rad/s²
  (T0=10s·5고조파 설계라 실제 최대는 수 rad/s — 범위 제약이 지배)
- 4-bar 폐쇄: cvt_core.closure(l_i=30mm) 전 샘플 수렴+잔차<1e-8, 평행사변형 qk=qc 확인
- 허벅지-정강이 충돌: 무릎각(=크랭크각)이 실측 방문범위 내 + 원본 MuJoCo 모델 접촉검사 0건
- 시작/끝 정지: dq(0)=dq(T0)=0 (a계수를 Σk·a_k=0에 사영) → 검증 **전체 PASS**

읽는 법과 정직한 해석:
- 점프 데이터는 가속·힘이 커서 원시 σ는 크다. 그러나 (i) 스탠스행은 구름 무슬립·레일
  무마찰·접촉 가정 위에 서 있고(가정 오류 = 바이어스), (ii) 폐루프라 여기 방향이 게인에
  종속이며, (iii) **마찰열이 관성 스팬과 뒤엉켜 있다** (분리도 0.47 — Phase 1의 0.40~0.44 재확인).
- 설계 궤적은 접촉/구름 가정이 **아예 없고** 마찰-관성 분리도 0.99로 사실상 완전 분리 (fv_hip=0.98, fc_hip=0.99, fv_knee=1.00, fc_knee=1.00).
- 나이브 사인(동일 주파수·동일 진폭·동일 위상)은 두 관절 운동이 완전 상관 →
  cond 2761444008980 (수치상 랭크 결손). "움직이긴 다 움직였는데 조합을 못 가른다"의 전형.

- 30분 = 180주기 반복 → 유효 σ_min ≈ 0.06×√180 = **0.8 Nm** → 최약 베이스 조합의 상대 불확실도 ≈ 48.6% (스케일 단위).
- 캐리지를 **클램프로 고정**하고 돌릴 경우(ddbz=0 회귀자): σ_min=0.313, cond=233.4 — 두 모드 모두 커버됨.

## 6. 실행 절차 (사용자)
1. **PD 게인**: 데이터 세션 중간값 `120_2_120_2` (hip kp=120, kd=2 / crank kp=120, kd=2) 권장.
   첫 1~2주기는 `60_0.75_60_2`로 저게인 드라이런 후 이상 없으면 120으로.
2. **반복**: 1주기 10 s × 180회 = 30분. 5분(30주기) 단위 6파일로 나눠 기록 권장
   (파일 크기·중간 점검·온도 확인).
3. **기록할 것**: hip/knee xlsx 규약 전 채널(currentAngle/Velocity/**currentTorque(raw iTM)**/
   desired*), **Clutch.xlsx(l_i=30 확인용 — 무변속 가정 검증!)**, 모터 온도, 버스 전압,
   가능하면 베이스 레일 위치. GRF는 공중이라 무관.
4. 세션 전/후에 동일 첫 주기를 한 번씩 더 기록 (온도 드리프트 대조군).

## 7. 정직한 한계 (반드시 읽을 것)
- **PD 추종 오차가 실행 궤적을 뭉갠다** — 식별은 반드시 **측정된 q/dq**(엔코더)로 재구성한
  회귀자로 수행할 것 (desired 아님). ddq는 Phase 1과 동일하게 SG(win=11, poly=3) 미분.
- 토크는 currentTorque(raw iTM)를 **Paper a_hat 변환** 후 사용 (Nm 아님 주의).
- 레일 마찰 = 0 가정 (비행 회귀자의 bz행 소거). 마찰·걸림이 있으면 힙/크랭크 행에 바이어스
  → 캐리지 고정(클램프) 모드로도 한 세트 찍으면 교차검증 가능 (ddbz=0 회귀자 사용).
- 저주파 설계(최고 0.5 Hz)라 가속 여기가 작아 순수 관성 조합의 σ는 마찰/중력
  조합보다 작다. 관성 정밀도가 더 필요하면 T0 단축/고조파 추가 후속 설계.
- l_i=30mm 평행사변형 축퇴로 crank/coupler/calf 관성 일부가 묶여 있음 — CVT(l_i=25.08)
  공중 세션을 추가하면 Phase 1 기준 +4 조합이 풀림 (후속 제안).
- 서로게이트 보간 상대오차 2.4e-04 (최종 수치는 정확 빌드로 재평가).
