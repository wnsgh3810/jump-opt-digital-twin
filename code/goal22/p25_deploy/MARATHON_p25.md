# MARATHON p25 — 배포 리허설: 최적화 총력전 → PD 배포 → τ-fidelity (2026-07-17, /goal p25)

목표: **승격된 p24a 트윈** 위에서 점프 궤적을 여러 방법으로 최적화하고, 그 궤적을 (q_des, dq_des)로
PD 배포했을 때 ① 계획 토크 τ*와 측정(PD 산출) 토크의 일치(τ-fidelity) ② 점프 높이의 실현률을
방법별로 비교한다 — 헌법의 최종 목적("최적화 궤적으로 PD 제어 시 측정 τ ≈ 계획 τ*")의 전면 예행.

## 지표 (선고정 — 불변)

각 방법 m의 궤적 T_m에 대해:
```
h_plan  = 최적화기 자신의 롤아웃 apex 높이 [m]
h_PD(g) = (q_des,dq_des)를 게인세트 g로 트윈 폐루프 PD 배포했을 때 apex [m]
F_τ(g)  = RMSE(τ_PD − τ*) / RMS(τ*)  (스탠스 구간, 무릎+힙 합산 — 낮을수록 좋음)
H_fid   = |h_PD/h_plan − 1|
주 순위 = h_PD (배포 성능) · 부 지표 = F_τ, H_fid, 게인 강건성 (g 2종: 중간 120_2_120_2 / 고 150_2.2_500_4)
```
**개념 주의 (명문)**: 트윈 안 리허설에서 플랜트=트윈이므로 F_τ의 성분은 모델 오차가 아니라
**PD 추종 한계 + 궤적의 공격성**이다 — 즉 이 마라톤은 "궤적의 배포 가능성"을 재는 것이고,
실기 배포 시엔 여기에 모델 오차(P24까지 줄여온 그것)가 가산된다.

## 바닥/기준선

- 실측 최고 점프: **0.98 m** (0602). G20(P19 시절) NLP: τ* apex 1.063 m, 헤드룸 +14cm의 원천 =
  hip 8~14 rad/s 미개척 대역. p24a 트윈에서의 재산정이 이 마라톤의 베이스라인.
- 공급 천장: raw ±35.5 (클립) — a_hat 역변환 경유. 관절 범위: 실험 방문 범위 +10% 마진.
- F_τ 바닥: 폐루프 인식 최적화가 이론상 최저 (배포 성능을 직접 목적화) — 개루프 최적의
  F_τ 열화가 "개루프≠폐루프" 독트린의 정량 재현이 될 것 (예상 가설).

## 태스크 정의 (공통 고정)

수직 최대 점프: 시작 = 실험 웅크림 자세(0602 시작 q 사용), l_i=30 flip 모델(p24a 전 층 포함),
horizon 0.6s, dt=트윈 기본. 목적 = base apex 최대. 제약 = 공급 천장·관절 범위·발 이지 전 미끄럼 없음.
