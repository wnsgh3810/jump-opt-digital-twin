그것을 빠짐없이 다시 읽고, **무엇이 진짜 문제인지 스스로 판정하고**, 해결하고,
앞으로 돌릴 장시간 탐색 실험을 설계하고 코드를 쓴다.

**최종 목표는 셋을 전부 성공시키는 것이다: ① 짐 지고 일어서기 ② 수직 점프 ③ 수평 점프.**
이 로봇은 2자유도 4절 링크 변속기를 가진 단족 점프 로봇이고, 몸통이 수직 레일에 매달려
위아래로만 움직인다. 궁극의 판정 기준은 **최적화한 궤적으로 실로봇을 PD 제어했을 때
측정 토크가 계획 토크와 일치하는가**이고, 그러려면 모델 값이 **물리적으로 옳아야** 한다
(용도가 해 본 적 없는 동작의 예측이라, 점수만 맞춘 모델은 외삽에서 무너진다).

2. **데이터 유효성은 데이터 사전과 대조하고, 애매하면 나에게 물어라.**
   전례: 어느 세션의 유효 조합이 사전에 **반대로** 적혀 있었다.
3. **긴 탐색을 돌리기 전에 채점하는 쪽이 멀쩡한지 먼저 재라.** 심판이 망가져 있으면
   탐색은 몇 시간을 엉뚱한 목표로 최적화한다. 실제로 그럴 뻔했다.
4. **파라미터 하나만 실측값으로 바꾸면 대개 나빠진다** — 다른 값이 이미 그 오차를 흡수해
   놓았기 때문이다. 실측값은 탐색 축의 **범위와 출발점**으로만 넣고 같이 재적합시켜라.
   탐색이 실측을 **모른 채** 그 근처에 앉으면 그것이 독립 확인이다.
