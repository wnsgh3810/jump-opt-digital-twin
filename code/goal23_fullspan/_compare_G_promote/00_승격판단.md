## ⚠ τ 환율 주의 (표에서 τ 가 나빠 보이는 이유)
그래프의 **'실측 τ' 는 진짜 실측이 아니다.** 모터가 기록하는 것은 *명령* 토크(raw)뿐이고,
거기서 관절 축토크를 얻으려면 **환율(변환식)** 이 필요하다. 그런데
- p24 는 `a_hat` 환율을 쓰고,
- 마라톤G 는 **분동으로 교정한 정본곡선**(`canon_cap`) 환율을 쓴다.

그림의 '실측 τ' 선은 `a_hat` 으로 그려져 있다 = **p24 자신의 환율**이다.
환율이 다른 두 값을 같은 자로 재면, 환율 차이가 그대로 오차로 계상된다.

실제로 **동역학을 전혀 섞지 않고** 두 환율의 차이만 재면 (점프 창, 46 trial):
```
RMSE(canon_cap − a_hat)   τ1(힙) 2.16 Nm   τ2(무릎) 3.66 Nm
```
표에서 τ 가 나빠진 폭(ModeA τ1 +0.45 · τ2 +0.61)은 **이 환율 차이보다 훨씬 작다.**
즉 τ 열은 마라톤G 의 동역학이 나빠졌다는 뜻이 아니라 **자를 p24 것으로 썼다**는 뜻이다.
→ 승격 판정은 **q·dq 로만** 한다 (정본 심판 J_G 도 τ 를 안 쓴다). τ-fidelity 를 제대로 채점하려면 먼저 **환율 자체를 실측으로 결착**해야 한다 (이월 과제).
