## 문헌·오픈소스 조사 결론 (07-29 밤, 웹 에이전트)
1. **내장 스프링 정석 = Cassie 패턴**: 직렬 힌지 + joint stiffness + **armature(질량행렬 대각 가산 = 고기어비
   병조건 직접 해소 — goal19 실패 원인의 정답)** + joint damping(암시적 적분) + implicitfast. 로터 질량 바디
   금지, armature로 대체. 강한 스프링 검증은 RK4 대조.
2. **히스테리시스 비대칭(로딩178/언로딩266)은 관측면 유지** — PACE도 탄성 흡수 처리. 플랜트엔 대칭 스프링,
   방향별 차이는 커맨드층에.
3. **원판 발 가장자리 접촉점 이동**: menagerie는 전부 구발 — 우리 원판(⌀42) 실린더는 기울면 림 접촉으로
   접촉점이 스스로 이동. 세션 δx·H29의 기구학적 원인 후보 → 현행 실린더 geom의 림 접촉 거동 검증 우선.
4. **PACE per-joint bias q̃b** = 우리 세션 정적 잔차의 표준 관행화. 세션 시동 프로토콜(정적 2~3자세+공중
   chirp 20s) 문헌 근거 확보. PD 게인 공동최적화 금지(비유일성) 재확인.
5. **★신규 미탐색 축 — 방향 의존 효율 η^sign(τ·ω)**: 유성기어는 전동/역구동 효율이 다름. "푸시에서 실기가
   더 빠름"(H29)과 부호 일치 — 파라미터 소거 후 남은 구조 축. Day1 판별 실험 후보 1순위.
6. 데이터 프로토콜(Hwangbo): 광대역 여기(1~25Hz)+접촉 포함 — 차기 실기 fit 세션 설계에 반영.

## fs_model v1 설계 (확정)
- hip: base→[hip_motor 힌지: armature=0.01(반영 로터), 액추에이터·인코더 여기]→소질량 중간체→
  [hip_spring 힌지: stiffness≈150 선형 + 러너 2단 보정 qfrc, damping b_s]→thigh (Cassie 패턴)
- knee: 현행 유지 (병렬 유연 0.404 + h_load 스프링 + 지지법칙) · 발: 실린더 유지 + 세션 δx 장착 오프셋
- 적분기 implicitfast (RK4 대조 골든) · 커맨드층 잔존: 클립·a_hat·knee α (hip α는 창발로 대체)
- 세션상수 주입: {k_s 스케일, δx, o1/o2} ← fs_calib 하강 창
- 골든: ①수치 안정(발산 0, 에너지 표류) ②온건역 변형 C 등가(±10%) ③기존 정적 감사 재현
