## Phase 0 발견

### G-F1 ★ ModeA 폐쇄 초기화 버그가 개루프 쪽에 남아 있었다 (수정)
마라톤F의 F3(F-H10) 픽스 — CVT(l_i≠30)는 평행사변형 초기화가 4-bar 폐쇄 모순 → 솔버 스냅 —
가 **`rollout_cl_fs`(CL)에만** 적용되고 `rollout_ol_fs_b`(ModeA)에는 없었다.
결과: U-보드 MA 0429 = **q2 494°· dq2 136 rad/s 발산**. CL은 정상(q2 4.69)이라 CL만 보던 동안
드러나지 않았다. 수정 = CL 경로 미러 (`cvt_init` 5q 폐쇄해 + d(qpos)/dq2 수치미분 속도).

| 0429 ModeA | 픽스 전 | 픽스 후 | 변화 |
|---|---|---|---|
| q1 [°] | 28.71 | **1.54** | −95% |
| q2 [°] | 494.46 | **19.43** | −96% |
| dq1 [rad/s] | 10.39 | **1.23** | −88% |
| dq2 [rad/s] | 136.27 | **15.88** | −88% |

비CVT 9세션 전 채널 **소수점까지 불변** (`cvt_init`이 None이라 분기 자체가 안 걸림) — 확인 완료.
남은 문제: 0429 q2 19.4°는 여전히 전 세션 최악 (차악 0724 12.6°). CVT 전달 형태는 Phase 2 과제.

### G-F2 α_knee는 벨트 직렬탄성으로 정량 설명된다 (사용자 질문의 답)
관측 α표 {kp 60:0.85, 120:0.789, 250:0.656, 500:0.40}에 **단일 상수** k_b로
α = k_b/(k_b+kp)를 맞추면 **k_b = 399.8 raw/rad, R² = 0.9632**.
준정적 유도: 모터-링크 사이 벨트 강성 k_b, 모터측 PD면
τ = (kp·e + kd·ė)·k_b/(k_b+kp) → 즉 **α는 fudge가 아니라 벨트의 직렬 컴플라이언스**.
잔차 부호가 kp=250에서 +0.041, kp=500에서 −0.044로 체계적 → 단일 선형 스프링보다 약간 복잡
(하중 의존 또는 추가 요소) — Phase 2에서 명시 SEA로 판별.
**단, 이 유도는 kp와 kd에 같은 α를 준다** — 실측 α_kd 0.2 ≪ α_kp 0.656은 설명되지 않는다.
가설: qd 4ms 스큐 미보정 + τ̇ 항 + dq 원시차분 노이즈가 kd 항을 오염시켜 적합이 kd를 줄인 것
(마라톤C: 스큐 미보정 시 push에서 kp·e 25~30% 과대). Phase 2 판별 대상.
