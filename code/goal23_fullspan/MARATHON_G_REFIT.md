### G-F2 α_knee는 벨트 직렬탄성으로 정량 설명된다 (사용자 질문의 답)
관측 α표 {kp 60:0.85, 120:0.789, 250:0.656, 500:0.40}에 **단일 상수** k_b로
α = k_b/(k_b+kp)를 맞추면 **k_b = 399.8 raw/rad, R² = 0.9632**.
준정적 유도: 모터-링크 사이 벨트 강성 k_b, 모터측 PD면
τ = (kp·e + kd·ė)·k_b/(k_b+kp) → 즉 **α는 fudge가 아니라 벨트의 직렬 컴플라이언스**.
잔차 부호가 kp=250에서 +0.041, kp=500에서 −0.044로 체계적 → 단일 선형 스프링보다 약간 복잡
(하중 의존 또는 추가 요소) — Phase 2에서 명시 SEA로 판별.
**단, 이 유도는 kp와 kd에 같은 α를 준다** — 실측 α_kd 0.2 ≪ α_kp 0.656은 설명되지 않는다.
가설: qd 4ms 스큐 미보정 + τ̇ 항 + dq 원시차분 노이즈가 kd 항을 오염시켜 적합이 kd를 줄인 것
(마라톤C: 스큐 미보정 시 push에서 kp·e 25~30% 과대). Phase 2 판별 대상.

### G-F6 ★ 그 폴더의 레거시 시스템 동정 결과는 **단위가 섞여 있어** 그대로 못 쓴다

 τ1 ← gAv·cos q1 + gBv·cos(q1+q2), τ2 ← gBv·cos(q1+q2).)
→ Phase 1 과제 = **a_hat(Paper) 변환 후 재적합**. 이때 P_MODEL의 질량셋도 현행과 다름
(m1 1.05213 vs 현행 0.91281, m_c 0.80898 vs 0.65601) — 어느 쪽도 실측이 아님(G-F3).
