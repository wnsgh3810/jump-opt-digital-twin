# 슬립·구름 전수 측정 — 산출물 모음 (마라톤G, 2026-08-09)
## 무엇을 잰 것인가
발이 땅 위에서 **미끄러진 양(슬립)** 과 **굴러간 양(구름)** 을 나눈 것이다.
바퀴가 굴러가면 발 위치는 변하지만 미끄러진 건 아니다 — 그래서 둘을 나눠야 한다.
```
슬립(t) = Δx_발(영상으로 잰 실제 이동) − r · Δθ_발(엔코더로 계산한 회전)
        r = 20mm (발 바깥지름 40mm = 금속판 30 + 고무 5×2, 사용자 실측)
```
영상은 세상 좌표에서 '얼마나 갔나'를, 엔코더는 로봇 내부 형상에서 '얼마나 굴렀나'를
알려준다. 어느 하나만으로는 슬립을 못 구한다.

## 자(mm/px)는 어떻게 정했나
**발 금속 원판 30.0mm** 을 자로 쓴다. 발과 같은 깊이에 있어 원근 왜곡이 없다.
**영상마다 다시 잰다** — 카메라 거리·줌이 세션마다 다르다 (금속판이 20~59px).
구 발판 플레이트 120mm 자(0.7453)는 폐기 — 발보다 뒤에 있어 24% 틀렸다.

## 읽을 때 주의
1. **QC 경고가 붙은 trial 은 숫자를 그대로 믿지 말 것.** 특히 `동기 ±1프레임 → 푸시슬립 ±N mm` 는 24fps 에서 푸시가 5프레임뿐이라 생기는 한계다.
2. **부호**: + = 화면 오른쪽 = 모델 +x.
3. **푸시가 지배한다.** 정본 trial 에서 전체 슬립의 84% 가 푸시~이륙 구간이다.
4. 그림은 하나도 지우지 않았다 — 실패한 판독 그림도 남아 있다 (무엇이 왜 틀렸는지가 다음 사람에게 제일 중요하다).
