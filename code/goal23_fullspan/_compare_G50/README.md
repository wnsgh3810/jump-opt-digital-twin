## ⚠⚠ τ 열을 읽는 법 (반드시 먼저 읽을 것)

**τ 열은 이 스택에서 성능 지표가 아니다.**

ModeA 의 τ 패널은 `sim 인가 토크` 를 `d["a1"] / d["a2"]` 와 비교하는데,
`fs_data.py:115` 에서 **`a1 = ahat_np(raw1, v1)`** — 즉 **기준선 자체가 a_hat 변환값**이다.

| | 인가 토크 | `d["a1"]` 기준선과의 거리 |
|---|---|---|
| **OLD (배포모델)** | a_hat | **구조적으로 0 근처** |
| **G50 (현행)** | 정본곡선 + 측 (분동 A급) | 두 환율표의 차이만큼 |

⇒ τ 열의 "악화"는 **플랜트 성능이 아니라 환율표를 고친 분량 그 자체**다.

### 그럼 τ 는 어디서 채점하나
- **폐루프(CL)** 에서만 의미가 있다. 거기선 PD 가 명령을 **만들어내므로**
  `sim 명령 s1/s2` ↔ `실측 명령 raw1/raw2` 를 **raw 단위**로 비교할 수 있다 (환율표 무관).
- 그 자로 재면 G50 은 **τ1 −1.5% · τ2 −15.1%** 로 개선된다 (`_G48_guards.py`).
- ModeA 는 **측정 토크를 주입**하므로 원리적으로 τ 를 채점할 수 없다.

⇒ **이 표에서는 q1 · q2 · dq1 · dq2 네 열만 보라.**
