# 스프린트 B — *3 전사(공중→내려놓기) 데이터 전면 연구 (2026-08-01 개시)

사용자 제공: 전 세션 hip3/knee3/GRF3.xlsx (66 trial 실데이터, harness_output 합성분 제외 확인).
*3 = *2의 상위 집합 (앞에 ~30s 전사: 미활성→모터 활성화→공중/내려놓기→접지 정지→실험).
훅: *3 쓰기 금지 등록 완료. 0324(HO)의 *3은 센서 진단 전용 (fit 무관 — 규칙 유지).

## 목표 (H5 3성분의 실측 분해)
①전기 영점: 미활성 구간(정확-0 스팬)·활성화 스텝·공중 정지 보고값으로 세션/trial별 센서 영점 측정
②실제 힘: Δ(접지−공중) = 상수 오프셋 무관 하중 응답 → 플랜트 접지 모델 직접 검증
③재구성: bias = 영점 + 실제 힘 + 잔여(동적 결손) — A6 움직임 증인과 3자 대조
④모델 반영: 영점 차감 재감사·재채점 (τ1 정직 개선 가능) + 배포 절차에 '공짜 영점 캘리브' 편입

## 지표 (선고정)
- 성공 = 세션 bias(감사값)의 분산이 (영점+실제 힘) 실측으로 설명되는 비율 (R² 세션 간)
- 가드: 움직임 채널 비악화 (모델 반영 단계에서)
- 부수: 22/25 게이지·25/27 동적 결손과의 합류 여부

## Phase
0. 정찰 (fs3_recon — 진행): trial별 미활성 스팬·활성 스텝·공중/접지 정지 창·보고값
1. 영점 표: 공중 정지 raw vs 트윈 공중 유지 예측 (base 핀 공중 모델 — F47 기계 재사용) → 잔차 = 영점 후보
2. 하중 응답: Δ(접지−공중) vs 트윈 Δ예측 — 오프셋 무관 플랜트 검증
3. 3자 대조: 영점 실측 × 감사 bias × 움직임 최적 bias (A6) — 세션별 회계 폐합
4. 반영: 영점 차감 파이프라인 (관측 정정) → 재채점 → fs13 후보
5. 파생: 0422(신규 세션!) 편입 검토 · trial간 영점 변동(사이클 구조) · 활성화 스텝의 정체
