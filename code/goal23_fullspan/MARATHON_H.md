## ★ 슬립 지표 신설 (2026-08-11, 사용자 지시 "(가) 하고")

지표를 **다시 섞지 않는다.** q·dq·τ 는 나빠지면 안 된다는 사용자 조건이 있으므로,
가중치를 재배분하는 대신 **슬립 점수를 별도로 세우고 서로를 게이트로 건다.**

**정확도 점수 J_H** (기존 그대로) = 0.40×주입재생 + 0.40×폐루프 + 0.20×점프높이,
  각 항은 직전 스택을 1.000 으로 놓고 잰 값. **낮을수록 좋음.**

**슬립 점수 S_H** (신설) = (하강 슬립 차이RMS + 도약 슬립 차이RMS) / 2,
  현행(H1_260811)을 1.000 으로 정규화. **낮을수록 좋음.**
  · 하강 슬립 = 하강 시작(i_desc)~도약 시작 · 도약 슬립 = 도약 시작~이륙
  · 시뮬 슬립 = 접촉점 물질속도 적분 (구름이면 0 = 진짜 미끄럼) · 실측 = 영상 55 trial

**채택 규칙 (양방향 게이트)**
  · S_H 를 개선하는 후보 → **J_H 비악화** (+2% 이내) 필수
  · J_H 를 개선하는 후보 → **S_H 비악화** (+2% 이내) 필수

### 여기서 나온 구조적 발견
