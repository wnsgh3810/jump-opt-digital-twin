## 절대 하지 말 것 (전부 실제 사고)
- **자동 발 탐색을 다시 만들지 말 것.** 5회 다르게 실패했다 (`fs_slipmeas.py` 상단 주석).
  롤러는 저대비 원(20~60px)인데 화면에 작고 고대비인 볼트·나사·구멍이 수십 개다.
  점수 기반 전역 탐색은 구조적으로 후자를 고른다. **수동 시드는 2/2 성공.**
- **자를 하드코딩하지 말 것.** 영상마다 다르다 (fps 24/30/59.35, 해상도 720p/1080p/4K,
  발 금속판 지름 20~59px). `fs_vidscale`/`fs_slipmeas` 를 쓴다.
- **평활 금지** (푸시 급변을 −56.5→−38.5mm 로 깎았다), **이동중앙값 금지**.
- 슬립을 새로 구현하지 말 것 — 정본은 `fs_slipmeas.py`.

## 시드 판독 절차 (trial 하나당)
```
python _G75_seedzoom.py <세션>                # 1단계: 하단 격자 → 발 대략 위치
python _G75_seedzoom.py <세션> <cx> <cy>      # 2단계: r12~33 눈금 확대 → 정밀 판독
```
읽은 값을 `fs_slipmeas.SEED_CAL["<세션>/<trial>"] = (cx, cy, r_금속판)` 로 등재.
좌표는 **처리 해상도**(ds 적용 후) 기준. ds 는 `video_meta()` 가 출력한다.

★ **반지름까지 정확해야 한다.** 0424 에서 중심은 맞고 r 만 20(실제 33)이라 3회 연속 실패.

## 확정 사실
- 발 롤러 = **바깥 40.0mm = 금속판 30.0 + 고무 5.0×2** (사용자 실측). 접지 **r = 0.020 m**.
- 영상 자 = **금속판 30.0mm / 측정 px**, **영상마다 재측정**, 세션 내 상수 강제(2패스).
- 동기 = **마지막 접지 프레임 ↔ t_lo** (1프레임 어긋나면 푸시 슬립 11mm 변동).
- **FS_FOOTR=0.020 → J_G 0.7387 → 0.7356, 게이트 PASS** — 동결 최적에 편입 완료.
