## 폴더 구조
```
_compare/
├─ CL/<세션>/<trial>.png        폐루프 — 점프(push) 구간, 6채널 (실측/OLD/fs15)
│  └─ _summary.png              세션 채널별 평균 RMSE 막대
├─ ModeA/<세션>/<trial>.png     측정 토크 주입 재생 (0.4s 창 조각 오버레이)
│  └─ _summary.png
├─ CVT_CL/<trial>.png           0429 CVT 폐루프 (old α 5q vs 현행 fs 6q)
└─ CVT_ModeA/<trial>.png        0429 CVT 재생
```
표기: 각 셀은 `OLD→현행` 평균 RMSE (q[°]·dq[rad/s]·τ[Nm]).
생성: `python fs_compare_plot.py` (비CVT) · `python fs_compare_cvt.py` (CVT).
주의: held-out 0324는 ModeA 전용 (CL 미채점 규약). ModeA τ는 3자 공통 주입이라 차이가 작은 것이 정상.
