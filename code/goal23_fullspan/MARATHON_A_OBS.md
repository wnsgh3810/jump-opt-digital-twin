# 스프린트 A — 관측·bias 마무리 (GOAL23 후속, 2026-08-01 개시, 목표 ≤1일)

## 목표
모델 단순화·물리 번역 (정확도 개선이 아님): ①관측층을 모터측 단일로 확정 (스프링측/블렌드/w 폐기)
②bias의 모터측 이관 검증 (F56 처방 — 회계 일치) ③bias 3성분 표 전 세션 (Δθ₂·δx·상수 오프셋)

## 지표 (선고정 — 불변)
- **가드(엄격)**: 움직임 4채널 (q1·q2·dq1·dq2, 푸시+전구간) A1 기준 대비 비악화 (노이즈밴드 ±0.03)
- **τ1**: 정의 변경(모터측 단일)이므로 A2에서 재기준 → A3(bias 이관)가 그 정의에서 개선하면 채택
- **단순화 계수**: 제거 노브 수 (w 1개 + trial클립 43개 → 0), bias 번역 세션 수
- 바닥 참조: τ1 0.31 (Day0, 불변)

## 구성 정의
- A1 기준 = FS_FIXED=1 (bias 0.85·k_d 5@−128) + blend 0.5 + 단일 클립 20.5 (F52+F54 정직판 첫 원패스)
- A2 = A1에서 관측만 모터측 단일 (FS_TAUOBS=lpf)
- A3 = A2 + FS_BIAS_SIDE=motor (bias를 ctrl·관측에 동시 반영 — 회계 일치 시험)
