## ① 점수의 비중을 무게가 말한 대로 만든다 (필수)

**문제 (5 회차에서 실측)**: 무게는 0.27/0.15/0.27/0.07/0.14/0.10 로 줬는데, 각 판의 값 크기가
달라서 점수에서 차지하는 몫이 **일어서기 47% · 매달림 28% · 점프 전부 24%** 가 됐다.
개선 여지도 느린 동작 쪽이 10 배 커서 **탐색이 일어서기만 쫓을 유인**이 있었다.

**고침**: 각 항을 **배포 스택에서의 값으로 나눈다.**
```
J = Σ 무게 × (그 판의 값 ÷ 배포 스택에서 그 판의 값)
```
그러면 출발점에서 모든 항이 1.0 이 되어 **무게가 곧 비중**이 된다. 0 이 완벽인 성질은 유지된다
(값이 0 이면 항도 0). 배포 스택 기준값은 `_ensure()` 가 이미 계산하는 `_CUR` 에 있다.
⚠ 기준선이 바뀌므로 **점수를 이전 회차와 직접 비교하면 안 된다** — 새 1.0000 을 다시 세울 것.

## ② 일어서기 창을 짧게 (필수)

**문제**: 창 전체(1.3~1.9초) 개루프 재생이 **발산한다** — 무릎각 절대 오차 36.7 / 45.3 / 85.7 /
**160.2** 도. 지금 점수는 "물리가 얼마나 맞나" 가 아니라 "얼마나 빨리 무너지나" 를 재고 있다.

**고침**: 창 상한 **0.4 초** (그러면 절대 오차 16~62 도로 내려온다) 또는 국소 진단과 같은
**0.15 초 재앵커** 방식. 후자가 물리적으로 더 깨끗하지만 창 수가 늘어 평가 시간이 는다.
권고: 우선 0.4 초로 바꾸고, 평가 시간이 허락하면 재앵커로.
※ 창 상한 1.5→2.0 변경은 효과가 없었다 (움직임이 2~3 조각이라 이미 0.8 초보다 짧다).

### P1 을 미리 시험한 결과 (08-14) — 엄밀한 형태는 **틀렸고**, 약한 형태는 **맞다**

무릎 건마찰을 **실측 0.423 으로 올려놓고** 속도비례 마찰을 훑었다 (값 = 일어서기 판, 0 이 완벽):

| 무릎 속도비례 | 천장 그대로 | 하중비례 0.30 |
|---|---|---|
| 0.000 | 5.215 | 2.120 |
| **0.034 (실측)** | 4.886 | **1.846** |
| 0.150 | 3.385 | 1.643 |
| 0.228 (지금) | **2.732** | **1.601** |

· **엄밀한 P1 은 틀렸다** — 하중 비례를 넣어도 속도비례는 여전히 높은 쪽을 원한다.
  두 항은 완전한 대체재가 아니고, **두 항으로도 못 채우는 저항이 아직 남아 있다.**
· **약한 형태 P1' 은 맞다** — 실측 조합(0.423 + 0.034)을 쓸 때의 손해가
  **79%(4.886 vs 2.732) → 15%(1.846 vs 1.601)** 로 줄었다. 그리고 그 1.846 은
  지금 쓰는 모델(3.163)보다 이미 **42% 좋다.** 물리적으로 옳은 값으로도 잘 맞는 모델이

· ☠ 첫 시험은 **설계가 틀렸다** — 건마찰을 지금 값(실측의 1/3.6)에 묶어 둔 채 속도비례만

  결과가 어긋났을 때 해석을 바꾸는 대신 시험을 의심할 수 있었다.

**새 예측 P5**: 속도비례가 실측의 6.7 배를 계속 원한다는 것은 **속도에 따라 커지는 손실**이
아직 없다는 뜻이다(역기전력·감속기 효율 — 명령 채널로는 원리상 안 보이는 것).

# ★ 08-14 저녁 2차 — 변속기 축 훑기 + 모터 모델 (사용자 요청·질문)

## ⑦ 손실이 "짐 무게"에 비례한다는 내 표현은 틀렸다 — **명령 토크에 비례**한다
사용자 지적: "무릎은 결국 조인트·모터고, 더 무거운 짐일수록 더 큰 토크를 요구하는 것 아닌가?
무게로 퉁쳐도 되나?" — **맞다. 그리고 모델은 이미 그렇게 돼 있다.**

  무릎 손실 = (0.18 + fc1·**|명령 토크|**) · tanh(무릎 각속도 / 0.3)

짐은 **몸통 질량으로만** 들어간다(`FS_MASS = 기본질량 + 짐`). 짐이 무거우면 명령 토크가
커지고, 그래서 손실이 커진다 — 사용자가 말한 경로 그대로다. 내가 "짐이 무거울수록"이라고
쓴 것은 **결과를 기전인 것처럼** 말한 것이라 틀렸다.

물리 기전: 4절 링크의 핀과 감속기 기어 이가 서로 눌리는 힘은 **전달 토크에 비례**한다.
쿨롱 마찰은 누르는 힘에 비례하므로 손실도 토크에 비례한다 — 이것이 곧 "전달 효율" 이다.
08-07 분동 왕복 실측이 정확히 이 형태였다: 무릎 0.135 + **0.1197**·|명령| (효율 88%) ·
힙 0.278 + **0.0029**·|명령| (효율 ≈100%). 무릎만 4절 링크와 벨트를 거치기 때문이다.

(두 재생 경로 모두). 배수 손잡이 = `FS_CVT_DISS_SCALE`. 일어서기는 **통짜** 재생.
