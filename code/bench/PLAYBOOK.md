# PLAYBOOK — 마라톤 방법론 (온디맨드 문서, /goal이 참조)

목적: 잘 됐던 세션들의 **사고 절차**를 명문화해 어떤 모델(Opus 포함)이 돌아도 같은 규율로 진행되게 한다.
정직한 한계: 가설 생성의 질과 판별 실험의 창의성은 문서로 이식 불가 — 이 문서는 바닥을 올리는 외골격이다.

## 1. 지표 선고정 + 바닥(floor) 계산 — 최적화 전에 반드시
- 마라톤 점수(지표)를 첫 시간에 **한 번 정의하고 끝까지 불변** (중간 변경 = 골대 이동).
- **바닥 계산**: sim 없이 데이터만으로 도달 가능한 한계를 먼저 구한다
  (예: P19 재구성 바닥 — 실측 (q,dq)를 명령 모델에 넣은 τ vs 실측 τ → "sim이 아무리 완벽해도 이 아래론 못 감").
- 바닥 대비 현재 위치로 "남은 헤드룸"을 선언하고 시작. 바닥 근처면 그 축은 종료 선언.

## 2. 진단 → 가설 → 최소실험 → 판정 루프
- **최적화보다 진단 먼저**: 그림을 뜯어보고 (구간 분해, 정적 감사, 에너지 원장) 오차의 "모양"을 특정한 뒤 가설을 세운다.
- 가설마다 **가장 싼 판정 실험**부터 (데이터만 → 스캔 → 단일 파라미터 → CMA 순).
- 모든 가설은 HYPOTHESES 로그에 행 추가: `| 가설 | 시험 | 판정(채택/기각) | 근거 수치 |` — 판정 없는 가설 금지.
- 기각도 성과다: REJECTED.md에 근거·재심 조건과 함께 기록 (소거의 가치).

## 3. 판별 실험 설계 (가장 강력한 도구)
한 관점에서 구분 불가능한 두 가설 → **구분되는 관점**을 찾아 실험한다. 검증된 실례:
- 스프링 배치 (crank vs calf): 평행사변형에선 수학적 동일 → **CVT 세션(l_i≠30)**이 축퇴를 깸 (P18b)
- 센서 편향 vs 플랜트 토크: Mode A에선 동일 → **폐루프(CL)만이 판별** (P18b 프리로드)
- 세션 캘리브레이션 vs 보편 법칙: **세션 간 일반화 시험** (2세션 학습→제3세션) (P19 커맨드층)
- 정적 감사 (유지토크): 참고 등급 (stiction 밴드가 판별력 약화) — 동적 심판이 최종.

## 4. 심판 구조 (게이트)
- **held-out(0324)은 fit 금지, 게이트 전용** — bench promote가 기계적으로 강제.
- CL 단독 fit 금지 (PD가 모델 오차 흡수) — Mode A 가드 동반. 단 순수 Mode A도 축퇴 방향이 있어
  **CL은 "Mode A 동률 해 중 선택자"로 목적에 포함** (P19 평결: Mode A 동률인데 CL 45.8 vs 38.1%).
- **개루프 최적 ≠ 폐루프 최적** (3중 확인: 지연·softsat·학습 FIR) — 커맨드층류는 물리와 폐루프 공동적합 필수.

## 5. 침묵실패 방역 (safe.py 의무 + 골든 재현)
- 새 심판/러너를 신뢰하기 전 **골든 재현**: 알려진 후보의 저장 지표를 재현하는지 확인 (bench eval의 REPRODUCED).
- XML 치환=xml_patch, 인덱스=qadr(이름 조회 — 평행사변형 축퇴가 인덱스 버그를 위장한 전례), JSON=atomic/read_json.
- 구조를 바꿨으면 컴파일된 모델(jnt_stiffness 등)로 적용 여부를 실측 검증.
- 과거 기각 축이라도 **구조가 바뀌면 재심** (stiction은 스프링이 있을 때 기각됐었다).

## 6. 병렬·기록 케이던스
- 긴 fit은 백그라운드 + 완료 알림 수확. 독립 조사(포렌식/웹리서치/문서화)는 서브에이전트 병렬.
- 발견 단위로 즉시: MARATHON 로그 갱신 → git 커밋 (수치 포함 메시지) → Notion 장(章) 추가 (이미지 검증).
- 마감 알람(cron) 시점엔 이미 다 기록돼 있어 랩업이 확인 작업이 되게.

## 7. 정직 관례
- 반전되면 즉시 정정 선언 (이전 주장 철회를 명시). 바운더리 추격·confound·크래시 trial은 각주로.
- 개선 주장에는 동일 지표·동일 평가기 비교만 (이종 지표 혼합 금지 — 부트스트랩 26.3%p 사건).
- "다 해봤다"는 금지 — 남은 축을 명시하고 소거 상태를 표로.

## §10 노션 기록 표준 (child 페이지 템플릿 — 2026-07-13 사용자 지시로 제정)

마라톤/goal 페이지는 **부모(요약 콜아웃 3개: 목적/한줄요약/방법론) + child 페이지들**로 구성.
각 child의 필수 구조 (순서 고정):
1. 💡 요약 콜아웃 (3줄 이내 — 이 페이지만 읽어도 결론을 알게)
2. 쉬운 설명 (비유 포함, 용어 최소) — 상세·수식보다 먼저
3. 수식/정의 (code_block) — 지표·프로토콜은 반드시 명문
4. 그림 (notion_kit.img — 업로드 후 verify_images 의무, 철칙 8)
5. 표 (수치는 표로 — 문장 속 나열 금지)
6. 한계/다음 (정직 섹션 — 못 가린 것, 공선성, 미검 항목)
7. 📁 산출물 위치 콜아웃 (코드·그림·데이터 경로 — 모든 child 필수)
구현: `notion_kit`의 create_page/append/callout/table/img/verify_images.
실례: build_notion_p20.py (P20 마라톤 — 이 표준의 첫 적용).

## §7 FULLSPAN 마라톤 확립 절차 (GOAL23, 2026-07-30)
- **준정적 하강 창 캘리브 → 제어 창 제로샷**: 세션 상수(바이어스·관측 혼합비·간섭 강도)는 느린 하강
  창에서만 결정하고 푸시/점프 창은 검증 전용 (누수 금지). 전이 실증: bias(F5)·w(F23: 오라클의 97%)·
  CVT(F22). 원패스 자동화 = goal23_fullspan/fs_calib_all.py.
- **채점 기준 thm1 의무**: 실측 각도는 모터측 인코더 — sim 사지각과 비교하면 직렬 처짐이 유령 오차로
  낀다 (같은 버그 3회 재발: F15/F34c/F45). 새 러너는 fs_metric 문자 미러 + prehold 잔차 상수성 검사.
- **포화 판정 주의 (F54 정정)**: 상위 표본 CV '평탄도'는 매끈한 자연 봉우리도 통과 — 포화 단정은
  커맨드 초과의 직접 증거(레일 고착·지령 대조)가 있을 때만. 날별 피크 차이는 궤적 역학 요구량 차이가
  1순위 설명. 단위 규율은 유지: 토크 논의는 a_hat 축토크로 통일 (raw-as-Nm 라벨 함정 실재).
- **off-stop 창 선별**: 접촉 상태가 바뀌는 과제(s2s 착좌)는 실측 FK로 하중 경로를 판정해 물리 부재
  창을 채점에서 분리 (F25: 발산 220~267°가 전부 착좌 창 오염이었음).
- **소재지 3중 판별**: 각도 잠금 이상 요소는 좌표 분리 세션(CVT: 크랭크≠사지)에서 양 좌표 스윕으로
  모터 내부/사지 기하/기구 상태를 판별 (F43: 무릎 간섭 = l_i=30 상태 문지름).
- **운영영역 제로섬 경보**: 어떤 파라미터 변화가 세션군 간 개선↔악화 재편(전체 평균 무변)을 보이면
  파라미터 축이 아니라 운영 영역(깊이·슬립·궤적 유형) 의존 신호 — fudge 재도입 금지 (F33/F38).
